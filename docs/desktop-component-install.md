# 可选桌面组件的安装与升级

组件为 Windows 11 x64 的 HertzDesktop，共用歌词窗口、壁纸、托盘与设置。安装组件不改变 DBX 的播放或退出行为。当前 DBX 接入仍在实施；必须以实际组件清单和握手的协议能力为准，试产物不能作为已支持 DBX 的正式版本。

从对应插件候选的发布说明获取配套 `hertz-desktop-<version>-windows-x64.zip`，核对发布的 SHA-256。解压到 `%LOCALAPPDATA%\Hertz\Desktop\bin\`，保留 `hertz-desktop.exe`、`desktop-component.json`、`LICENSE` 和本文。不要把账号、插件数据或钥匙复制到这里。

DBX 采用独立启动方式：先手动运行 `hertz-desktop.exe`，再在受支持插件中连接。DBX 不代为启动组件。启动组件或打开设置不等于启用歌词或壁纸，窗口启用与音乐来源须在原生中心显式确认。

升级前从托盘正常退出当前组件，备份原有 `%LOCALAPPDATA%\Hertz\Desktop\config.json` 和旧组件包。确认新包的 `desktopBuildId` 与插件要求相同，再替换组件目录并启动。不要覆盖正在运行的 exe；升级失败时退出新组件，恢复旧包，必要时显式恢复配置备份。旧组件不能读取新配置时不要反复尝试保存，恢复备份将失去备份后的设置修改。

Standard 与 Full 可以共用匹配构建的组件；版本号相同并不保证构建匹配。不兼容的插件仍可正常使用原播放器，桌面连接需升级到配套构建。卸载某个插件不应删除另一来源的设置、共用组件或全局自启项。

独立版继续使用已有组件定位规则。若已有另一位置启动的全局组件或自启项，请在原生中心确认路径；不要同时启动两套组件争抢设置。
