# 主窗口位置与最大化恢复

2026-11-07 继续现行 Wry/Tao 主窗口路线。用户行为依据为 desktop-client §7.2，实施规格和计划见 `aegis/specs/2026-11-07-native-window-recovery-brief.md` 与对应计划。实现已接通，最终 Full 原生优化候选已通过十一组实际窗口验收。

正常窗口的外框位置、尺寸和最大化状态按 DataDir 保存。恢复使用当前显示器的真实工作区和 DPI，保留逻辑尺寸与偏移，并将整个外框放回可见工作区。原显示器消失时选择当前主屏；工作区小于通常最小窗口时允许缩小。使用系统标题栏、装饰和贴靠行为。

WindowLifecycle 继续持有原生设置所有权。`native_window_placement` schema1 保存正常外框、原工作区、缩放比例和最大化标志；未知字段、错误类型、无效矩形和未来版本拒绝。损坏或未读出的既有行保持原值，自动捕获不会替换成默认状态。

只有主窗口捕获位置。胶囊、最小化和隐藏期间的尺寸变化不覆盖正常矩形；最大化保留 Win32 正常恢复矩形，并将工作区坐标换算为屏幕坐标。隐藏恢复显式保留 `SW_HIDE`。用户跨 DPI 屏幕拖动按 Tao 提交后的当前矩形恢复，显示器拓扑与工作区变化另按保存矩形重新放置。

隐藏或最小化窗口在聚焦、退出确认前，先恢复 owner 已接受的正常快照，再显示并重新捕获。不能把隐藏期间的临时外框在显示后当成新的正常尺寸；实际原生退出旅程已发现并促成这项恢复顺序修正。

写入由现有设置锁串行化，250ms 合并一批变化，Tao 不做数据库 IO。失败保留最新意图并记录错误；后续变化和退出刷新可重试。退出先停止原房间和音频，再请求最后一次主窗口捕获并封闭后续写意图；捕获等待一秒，持久化等待两秒，超时不会阻止原有服务收尾。

普通 `PUT /v1/settings`、HTTP 和 DBX 的业务 JSON 恢复不能写这个专用键；普通 JSON 导出不包含它。受控界面偏好迁移也不包含机器几何。私有完整 SQLite 恢复点保留完整资料恢复语义。
