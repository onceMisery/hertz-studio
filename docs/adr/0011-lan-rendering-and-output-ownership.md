# ADR-0011 · 房间渲染、呈现提交与原生输出归属

状态：实施（2026-10-25）。本决策固定源码契约；设备支持与声学精度仍以[交付证据](../../evals/lan-sync/delivery-2026-10-25/README.md)中的实测范围为准。

## 决定

AppState 是业务队列与模式的唯一所有者，audio actor 与 RenderCore 共享单机和房间的解码、混音与 DSP。房间 producer 在固定房间格式中提前渲染；成员只接收这份 PCM，不各自下载原文件解码。主机收听也经过原生 Receiver。房间模式下旧 HTTP、RPC、AI 和内部播控入口在原裁决边界拒绝写入，不能通过另一套队列或播放器绕过。

渲染事实和呈现事实分开提交。已生成后继 PCM 不表示听众已听到下一曲；队列游标、歌名和历史按房间呈现边界提交。Prepare/Ready/Commit 绑定实例、房间、会话和 epoch，已 Commit 的前缀不可悄悄撤回。一次未确认的 next 只查询原操作终态，不自动重发相对写命令。

队列写入携带 `items: [{instance_id, resource_id}]`，保留项必须携带原实例 ID，新增项显式写 `instance_id: null`，由 Host 分配新 ID。同一资源的多次出现各有独立身份；重复实例、实例与资源不符、已移除实例和过期 revision 全部拒绝，不能按资源 ID 猜测原实例。AppState 仍是唯一业务队列，Host 只保存与它平行的实例身份元数据。未确认播控回执归属 `(room_id, instance_id, member_id)`，同成员网络重连后仍能查询原操作；换房、房主实例或成员时清理。

Receiver 的转换工作线程负责源相位与设备调度；ScheduledPcmQueue 唯一拥有接受后的设备时间网格，回调只读取有界预分配队列。预算、连续写和交接必须使用同一网格及其分数相位。后继段不得把缺失的真实旧尾帧变成计划静音；源尾完整、边界合法且后继实际写入后才能转移输出所有权，期限内不能完成则静音并重同步。有限测试音用最终帧序号结束，不用墙钟截断制造假欠载。遥测先采样、后取新鲜单调时间，一次门禁使用同一快照。

Windows 的 ScheduledOutput 使用独立的 WASAPI 呈现适配器，专用 MTA 线程唯一持有该设备会话、COM 接口和事件句柄；停止信号先唤醒并等待线程退出，再释放输出。它消费既有 ScheduledPcmQueue，不创建第二条业务队列、转换器或本地播放器。时间基准来自 IAudioClock 的 position / GetFrequency 与配对 QPC，按已提交帧网格推算下一帧的呈现时间；设备 position 不假设等于采样帧，QPC 的 100 ns 单位不当成原始计数器频率。GetPosition 定义的是当前呈现位置，不在投影上再叠加 GetStreamLatency 的最大延迟。CPAL 0.15 的 WASAPI 可写空间时间戳不再进入这条路径；其它平台继续保留各自后端能力标记。采样精度、位置连续性、欠载或设备失效不满足合同则静音并重新同步，不能改为墙钟播放。设备绑定包含原生后端与端点标识，旧 CPAL 校准不沿用。Receiver 按同一输出会话的累计时钟故障水位撤销旧计划，不能只观察短暂的 Invalid 状态；即使设备已完成 Reset 和时钟预热，也必须等待新的未来 Prepare/Commit。解静音携带已确认的故障代际，设备消费者在读取 PCM 前复核该代际，封住转换期间发生故障又恢复的竞争。

房间 TLS listener 独立于本机全权 API。mDNS 仅用于发现；邀请、指纹和系统凭据服务负责信任，控制与音频通道持续检查权限。任一通道失效先撤销输出，重连只加入新的未来播放点。关闭先封住 Receiver 注册入口，撤销并等待原生输出退出，再恢复暂停的本地模式；End 使用有期限的 WebSocket 关闭，不能以立即断 TCP 代替终止通知。

Admission 与一次性邀请由同一传输 owner 串行裁决：公开查找码不授权，申请查询必须证明持有独立 256-bit 秘密，批准才签发高熵邀请，配对原子标记申请已消费。消费后移除成员与撤销邀请分属不同生命周期。申请数、存活时间、来源和全局频率均有界。成员签发邀请必须持有独立邀请权限，且不能转授队列、播控、音量或邀请权限。mDNS Advertisement 的创建与销毁属于 Host，界面只提交可发现意图，不把失败的发布显示成可用。

独立服务的 Ctrl-C、系统退出按钮和插件宿主都调用 `AppState::shutdown`：先封住模式入口并取消未完成启动，等待 RoomManager、Receiver 与 ModeLease 的共同关闭屏障，Host 发送并排空 End 后才关闭本地 audio actor、删除服务发现。Guest 服务退出保留最近房间凭据；显式离开或收到 Host End 才删除该成员凭据。

插件主线程唯一持有 Runtime 与 Booted，在 `PluginServer::serve` 因 stdin EOF 或读取错误返回后显式等待同一关闭屏障，再允许 main 返回。SDK 工作线程只持 Runtime Handle；正在执行或排队的请求可以保留 `Arc<Plugin>`，因此不能依赖最后一个 Plugin 的 Drop 来结束房间或销毁 Runtime。

聊天有独立的存储、历史和低优先级发送预算，不持有音频租约。浏览器只管理本机界面；关闭浏览器不终止健康收听，全部音频端离场才按租约与宽限暂停。设备音量仅在本机应用，房间 DSP 只在共同渲染路径应用一次。已接受的本机音量命令沿同一有界 FIFO 顺序处理，不因媒体授权代际撤销而丢弃；故障恢复必须保留用户设置的静音，不能只更新设置投影而留存旧设备增益。

Host 保存与队列实例绑定的点歌人、成员投票和有界活动投影。投票不创建另一份业务队列；排序通过正式播放提交锁更新 AppState，仅调整可变后缀，保留当前曲与已经准备或分发的音频前缀。相同成员对相同实例至多一票，重连不重新计票。聊天歌曲卡片使用独立的结构化资源请求，持久化资源引用；每次读取重新解析当前分享权限，撤销分享后不再呈现歌曲卡片元数据或操作。

一起听工作区视图只拥有页面导航与 DOM，HertzRoom 继续唯一持有房间快照、请求、回执和资源 URL。退出工作区恢复紧凑房间播控，不结束健康的房间会话。主应用导航与工作区导航通过显式回调衔接，不新增播放器或业务快照副本。

工作区仅拥有导航与布局，配色及主题目录、当前值和持久化继续由既有全局 Theme 唯一持有；房内外入口修改同一个本机主题。主题不属于房间协议或 Host 权限，不将样式选择广播为房间状态。

个人收藏继续由既有 favorites 存储拥有，不属于 Host 的投票或活动状态。房主本机复用原 local 曲目身份，接收端以固定证书指纹与密钥派生的不透明稳定曲目引用保存文字快照。临时资源 UUID、成员凭据和封面 URL 不进入长期 LAN 收藏。本机原 ID 映射只出现在房主本机投影，接收端来源身份由原生连接覆盖为已固定证书。再次点歌先按当前分享范围解析稳定引用，再走同一队列裁决；收藏不构成音频读取或播控授权。移除分享切断后续解析和资源操作，个人已存文字快照不因此删除。

## 边界与 owner

在线来源于 2026-10-26 接入同一所有权边界。SharedLibrary 显式登记平台身份和解析引用；队列编辑只校验分享，不获取音频。房主在后台复用在线取流与渐进下载器，按约 1.5 秒压缩音频预缓冲（64–384 KiB，未知码率 256 KiB），尾部元数据容器等待完整下载。探测和初始 seek 在阻塞工作池完成，producer 仅安装 PreparedMedia；在线准备总期限 20 秒，本地仍为 5 秒。接收端继续只收 PCM，不取得平台直链、账号或下载职责。

同曲同请求音质的并发准备共享下载会话；当前、候选、后继和未退休解码器各持媒体生命周期引用。CacheLease 在这些引用消失前保护活动 `.part`、正式缓存及降档文件，手动清理和 LRU 均复核租约。最后使用者退出取消未完成下载，停止标记也中断阻塞读和定位。单机下载启动及注册与模式切换共用 play_commit；进入房间时先作废代际并取消、回收单机下载，禁止迟到取流重建同一缓存。分享 revision、播放实例和 epoch 仍由 Host 在异步结果提交时复核。

## 禁止回退

- 不复制第二套混音器或真实队列：否则单机与房间的 DSP、自然转场和退出恢复会分叉。
- 不以 render head 更新呈现历史：否则提前渲染的下一曲会在扬声器出声前出现在播放记录。
- 不在 Receiver 重建一套近似设备网格：否则跨段 snapping 与分数相位积累后会提交重叠帧或丢失尾音。
- 不以零填充代替缺失真实源帧，不先丢旧 owner 再检查交接：否则后继 PCM 可把真实断音伪装成计划静音。
- 不用放宽新鲜度、关闭时钟门禁或扩大缓冲掩盖时序失败：否则页面显示就绪而设备已脱离共同时间线。
- 不在回调分配、做格式转换、等网络或操作数据库：否则一端聊天、磁盘或网络阻塞会成为设备欠载。
- 不把 mDNS 地址当可信身份，不让控制连接代替音频租约：否则可越权加入，或关闭全部声音后房间仍无限播放。
- 不在旧原生 stream 退出前恢复本地播放器：否则离开/结束与迟到注册竞争会叠播两个输出。
- 不把数字无损传输、同机对时日志和两分钟运行当成跨机声学或八小时长稳验收：否则未测设备会被错误纳入精度保证。
