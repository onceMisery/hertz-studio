# 本地素材组合生成

在桌面设置的 AI 面板选择“组合场景”，选中已安装版本的素材，查看报价并确认本次生成。候选可以预览、保存到“我的场景作品”，随后使用原作品编辑器修改节点、效果、时间线和绑定，发布、导出 HWPK 或重新导入。生成、预览和保存不会自动应用桌面设置。

服务只接收最多 32 项临时资源别名、类型、尺寸或时长，共不超过 8 KiB。素材文件、原始名称、目录、许可文本和署名保留在本机。报价绑定这份素材快照的摘要；修改素材后必须重新报价。

素材必须是用户确认有权使用的内容，或许可证允许改编的资源。保存时将全部所选原稿与变体复制到新不可变包，保留完整署名和依赖闭包。新作品随后独立持有文件，运行和导出不依赖原作品的安装目录。

模型只能返回已发布的声明式组合数据，资源位置只能引用本次别名。原生接收后再次按结构化字段映射资源，核验固定版本、文件哈希、许可和真实资源预算，再进入原准备槽及唯一预览。生成子集最多 32 个节点、8 个效果、16 条轨道和 16 个绑定；普通作者编辑继续使用完整组合文档合同。长轨道逐页读取关键帧，修改单个关键帧不会上传整条轨道。

候选准备失败时保留原任务与错误，提供明确重试。服务明确拒绝受理后释放素材占用；连接中断且结果未知时保留原提交用于恢复。提交期间换 Profile 或断开连接后，已返回的服务受理事实仍关联到原素材映射，旧界面不会取得新的操作权限。关闭面板停止轮询，已确认任务按原期限继续。

每个服务会话最多保留 8 组素材快照，未使用快照 5 分钟到期；受理后的本机映射和只读引用最多保留至终态后 24 小时。保存后的作品与草稿不因原 AI 响应过期而丢失。候选目录和引用记录进入原升级备份与恢复流程。

当前验证使用本地 fixture，不需要 OpenAI key。真实模型的输出质量、速度和正式计费资格另行验收。外部 MCP 助手申请是 AI-06 的独立后续功能。

验证入口：`scripts/check-wallpaper-composition-ui-browser.js` 检查浏览器交互；`scripts/check-wallpaper-generation-native.js` 设置 `HERTZ_GENERATION_COMPOSITION_FIXTURE=1` 检查 Windows 生成、预览、保存、编辑、导出及重新导入。Standard/Full 和内嵌/独立宿主分别运行。当前切片的最终验收状态见 [实施记录](wallpaper-ai-generation.md)。
