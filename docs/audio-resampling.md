# S1：解码线程流式 sinc 重采样

当前交付是 S1 的实现与离线验证增量，**不是完整音质或发布验收**。实际声卡、长时间听测、弱机和其它 OS 尚未验证。它不扩大 [ADR-0007](./adr/0007-playback-transitions-and-intent-ownership.md) 的精确无缝范围。

## 接线和依赖

`vmusic-audio::resample::Converter` 替换原 cpal 解码线程中的线性插值。顺序保持为：源域解码 → 重采样/声道映射 → 设备域队列与 crossfade → 既有 EQ/增益/软限幅 → float32 输出。每个 deck 独立持有转换历史，音频 actor 和输出回调继续使用原控制归属。

播放特性固定使用 MIT 的 `rubato = 0.16.2`，关闭默认 FFT 特性；锁文件新增该包，复用既有数值依赖。此处选择已核验接口和 MSRV 的固定版本，不跟随最新版本。关闭 `playback` 时转换模块与 Rubato 均不编译；Standard 与 Full 使用同一实现。

参数固定为 `SincFixedIn<f32>`、512 输入帧、256 点 sinc、0.95 cutoff、256 倍表、Linear 表插值和 BlackmanHarris2 窗。这里的 Linear 是 sinc 表插值方法。升降采样比固定，不做漂移追踪。同采样率直接复制完整交错帧，保持有限样本的位模式，包括负零和次正规数；这不代表含 EQ/增益/限幅的播放器全链 bit-perfect。

接受采样率 1–768000 Hz、1–32 声道、输出/输入比 1/64–64；这些是输入与内存边界，质量测量范围是 44.1/48/96 kHz 单/双声道。不宣称其它组合已有同等级质量证据。系数和工作缓冲在解码线程准备，成功的 `process/finish/reset` 不分配或释放堆对象；解码器自身的样本转换和既有队列不属于这一零分配承诺。

## 流式契约

`process(input, output)` 返回实际 consumed/produced 帧数和 `NeedInput/NeedOutput`。缓冲必须容纳完整交错帧；输出容量为零时不接受输入。每次至多接收一个内部块，先排出待处理输出再接受新输入，小输出不会形成无界等待队列。输入或转换结果含非有限值时返回错误；调用方丢弃或 reset 转换器，不能把错误之后的历史当成可继续播放的流。

`finish(output)` 锁定已接受的源帧数，以零延拓补齐块和滤波历史，输出总长度固定为 `ceil(sourceFrames * outputRate / inputRate)`。边缘因此有滤波瞬态，不复制边缘样本，也不附加可听的超时长尾部。最多再运行两个 512 源帧块，无法收敛时返回错误。它可反复调用到 `Finished`，终态之后始终零产出；新输入需先 `reset()`。

`reset()` 清除部分输入、待排输出、滤波历史、计数和终态。seek 成功同时清解码器、转换器与设备 PCM 队列，再按目标设备时钟继续；自然 EOF 先 finish 再公布 deck EOF，保留 EOF 后 seek。主动 stop/下载中止不补尾。解码器要求 ResetRequired 时重置转换历史；实际 PCM 格式中途改变明确失败，避免把不同格式混入同一历史。首个非空解码块的格式为准，允许容器声明与实际 PCM 采样率不同。

转换与声道映射在队列锁外完成，锁内仅追加设备域样本。单声道复制，多声道到单声道求平均，其它布局沿用原通道映射；没有新增空间布局混音器。平均使用 f64 中间求和，防止有限 f32 的相加先溢出，播放器其余链路仍为 f32。

## 延迟与时钟

`Latency` 分别记录 512 输入帧块、128 输入帧滤波前视以及库报告的输出域 buffering delay；`Frames` 都带采样率。`tail_padding_bound()` 描述最多 1024 源帧的内部零输入，不是新增歌曲长度，也不能和输出帧直接相加。

Rubato 此版本的 `output_delay()` **不是需要从 PCM 开头删除的静音帧**。居中滤波器已按源时间线输出，错误删掉该数量会提前声音。脉冲定位回归要求四种转换的峰值与源位置差不超过一输出帧；这并不证明跨采样率精确无缝。seek 以后重新建立历史，不承诺与从歌曲开头解码至该点的波形完全相同。

原同采样率、已验证压缩 trim 的精确 gapless 条件保持不变；跨采样率仍明确绕过精确 gapless，可使用 crossfade。AAC 的 delay/padding 验证也没有因引入 sinc 而完成。

## 验证与限制

自动检查覆盖 44.1/48/96 kHz 所有采样率对、单/双声道、碎片输入和单帧输出逐样本一致；空与极短流、非整数长度、比例边界、有界 finish、非有限/格式错误、reset 三种中间状态、同率逐位复制和脉冲时刻。质量检查在去掉边缘瞬态后要求 1/18 kHz 通带增益误差小于 0.05 dB，96 kHz 降采样的 27/30/40 kHz 单音混叠投影低于 -80 dB。

后端回归使用实际 PCM 文件检查 EOF 长度、seek、声道映射和设备时钟，并保留压缩格式、crossfade、精确 gapless 边界及输出回调分配/争用检查。单独的分配计数窗口验证转换器 process/finish/reset；窗口不包括构造和销毁。

可复现 release 合成探针及本机结果见 [测量记录](../evals/resampling/v1/README.md)。CPU 时间包含转换和向预分配结果缓冲复制，不包括构造、设备回调或音频输出；准备时间另列。线性参考只作连续插值比较，不仿真旧实现的包边界行为。单音投影不代表宽带底噪、完整动态范围、主观音质或真实设备性能。

S1 剩余：真实歌曲与更多格式/异常语料、实际声卡和切设备/持续播放、弱机资源预算、跨 OS，以及绑定具体发布产物的听测与验收。当前报告 `realSoundCardVerified:false`、`releaseEligible:false`，不能将离线通过解释为路线图完成。
