# 壁纸前台窗口规则实施记录

2026-11-06。接通 `pauseOnFullscreen`、`pauseOnMaximized` 和 `applicationRules` 的设置、持久配置、逐显示目标策略与资源生命周期。运行设置页和壁纸、歌词共用已有草稿与一次 Apply。

## 行为与作用范围

- 全屏与普通最大化分别开关。前台窗口只影响其所在显示器；single/mirror 的其它屏继续运行，span 任一成员屏命中则整个目标暂停。
- 应用规则匹配 Windows 报告的完整可执行文件路径，最多 32 条。支持盘符绝对路径、UNC 和等价的 verbatim 前缀，统一大小写、斜杠及 `.`/`..`。不依赖窗口标题或文件名，不要求程序当前已安装。相对路径、设备命名空间、控制字符、重复身份和超限配置拒绝。
- 只检测前台应用。最小化、不可见窗口、桌面壳和本宿主进程窗口排除；路径读取权限不足时不匹配应用规则，全屏/最大化事实仍可使用。
- Pause 冻结已呈现画面；Stop 退出目标窗口、候选、静态交接帧与解码资源。二者均保留用户选择与轮播位置，解除条件后恢复原项；单屏视频恢复检查点，mirror 使用共享组时间。
- 原因独立叠加，解除应用规则不会清除手动暂停、锁屏、息屏或电池原因。独立预览不继承桌面前台窗口规则。

每 250 ms 采样一次前台事实，再投影给各目标。全屏进入门限 300 ms，最大化与应用规则 750 ms，退出门限 150 ms；实际观察延迟另受采样节奏影响。Pause↔Stop 切换时保留旧动作直到新动作稳定，不产生临时恢复间隙。

## 资源与恢复

暂停达到 285 秒时开始有界静帧交接，在生产 300 秒资源上限前释放视频/GL。GL 交接复用最后成功提交帧的音频、时间和播放输入，零增量重绘一次；不恢复调度器。原生位图按现有 `DesktopFrame` CPU/GPU 预算记账。

交接失败时退出旧资源并保留选择，不将辅助截图失败永久变成作品失败。退出 owner 等待真实 controller、读者及捕获工作区释放，再允许后续准入。资源故障时不能保证静帧保留，设置页显示实际错误。

只修改窗口规则不会重建当前 renderer、重置视频/轮播或重试已失败的条目。显式原设置重新 Apply 与重新挂载保留重试语义。已有失败视频的验证封面在 Stop 后可恢复，失败项不被跳过；保留的封面描述不占 decoder、GL 或呈现目标预算。

正常策略停止/恢复不消耗“120 秒最多三次”的渲染故障恢复额度。窗口全部释放后仍采样前台事实。设置页分别显示停止、暂停、静帧、真实失败和镜像组部分目标暂停；静帧存在不覆盖恢复失败的错误和重试入口。
