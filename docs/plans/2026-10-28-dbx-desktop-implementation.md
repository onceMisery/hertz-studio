# DBX 桌面歌词与壁纸实施记录

依据：[已确认设计](../desktop-dbx.md)。工作分支：`codex/dbx-desktop-design-review`。
用户要求：按方案实施，不走 TDD；采用实现后验证，保留所有安全、回归及发布门槛。

## 范围与硬约束

交付 Windows 11 x64 Standard / Full DBX 的可选只读桌面接入，复用 HertzDesktop。
基础插件未授权时无新 listener、凭据、发现记录、组件启动或安装前置；已授权的桥故障不影响 SDK、音频与原退出屏障。
不加入 Tauri、不新增网络监听、不增加播放 owner、不扩大房间权限。DBX 歌词播控在 native 与页面均禁用。
保留上一轮 `desktop-client.md` 的修改，不实施完整桌面主客户端。
