| 身份核验 | 原弹窗内展示完整地址与指纹；取消后保留输入；支持完整邀请消息与 8 位查找码，查找码只走发现和审批；直接加入超时后保留原邀请、禁用重复提交，查看结果只读查询 |

## 实现边界

继续使用现有 vanilla JS/CSS、HertzRoom、队列回执、房间裁决与 Rust 桌面宿主，没有引入另一个播放器或房间状态源。共享搜索新增可选 `query` 和 `library_search` 能力；无 query 时序列化省略字段，兼容旧房主的严格请求解析。文档见 [API](../api-routes.md) 和 [使用说明](../lan-listening-user-guide.md)。

选曲入队超时时记录原 operation；确认 applied／no_op 后清除对应选曲，旧按钮回调也不能重复入队。分享未知时查询已授权结果，不自动重发。清除本机选曲记录不撤销已经完成的分享或队列操作。新房间不继承旧房间的选曲恢复记录。

暂停音乐继续已有壁纸环境动画；全屏、锁屏和息屏等策略暂停才停绘。真实运行事实与已保存配置分别显示。

## 仍需人工发布验收

物理显示器热插拔、锁屏／全屏切换、实际 Windows 自启项切换、多电脑网络与扬声器，以及六名用户无引导任务测试，未以本轮自动化替代。小屏只表示窗口响应式，不表示手机可收听。跨机声学精度与互联网一起听也不属于本轮 UI 完成声明。

当前工作树同时存在其他进行中的修改；本次没有打包发布、覆盖正在运行的用户服务，或混合提交这些修改。
