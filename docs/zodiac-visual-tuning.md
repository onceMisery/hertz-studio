# 星座 Zodiac 视觉参数

「星座 · 十二星图」逐座汇聚、停留、散开。造型采用可识别的动物、人物与器物
剪影，各座采用独立配色的流动星尘与柔光轮廓，主星及浅色连线覆盖其上。可以拖拽环绕、滚轮
缩放、双击复位，低频和起音驱动呼吸与增辉。三维空间页另有一层观测题签：显示星座编号、
中英文名、宫位、主星与星线数量；悬停主星会增辉并浮出读数，点击触发脉冲并钉住读数；
指针移动时主体与前后景星尘以不同幅度偏移。

## 轮廓和坐标归属

`tools/zodiac-stage/src/figures.js` 是十二座轮廓、孔洞和主星坐标的唯一来源。
原始数据以左上角为原点的 100 单位画布手绘，导出时转换为 y 向上坐标。
白羊保留回卷角与四肢，狮子采用卧姿，巨蟹采用正面俯视；双子为相连的人形，
射手为拉弓人马，处女保留双翼、裙摆，摩羯保留羊首鱼尾。
用户的 11 张参考图包含两张射手，金牛与水瓶按同一视觉语言补齐。

`zodiac.js` 使用 three 已包含的 Earcut 对闭合轮廓及孔洞进行三角化，再沿最长边
细分到固定 560 个顶点。共享边两侧的面片同步切分，避免裂缝。
不会用无约束三角化连接蟹钳口、腿间、弓弦或秤盘悬绳之间的空白。
各座的原始轮廓及三角网按座缓存，换画质只改变点云量。
公开的 `delaunay2` 纯函数保留兼容，造型生成已改用 Earcut。

`shapeFit(i)` 根据轮廓的精确包围盒计算等比缩放和中心，落到 1.78 的设计框：

```text
k = min(2 * FIG_HALF_W / width, 2 * FIG_HALF / height)
worldX = (rawX - cx) * k
worldY = (rawY - cy) * k
```

网格、粒子、柔光与主星共用此变换。**星图不再独立放大或居中**，否则主星会
偏离对应的身体部位。主粒子按面片面积采样，18% 沿外轮廓采样以保留细节。
体积上限为 `FIGURE_DEPTH = 1.25`。星尘分三层：约 62% 落在近前壳，约 28% 落在中层，
约 10% 贴近背面；加法混合下仍以前壳为主要可读层，转动到侧脸时中层与背层提供真实厚度。
正面按到轮廓的距离隆起，背面向后延伸，边界侧壁封闭体积；主星、网格边与柔光贴合正面。
机身之外另有两层不随机位平移的星尘（中景 8.5–16、近景 4.2–7.4 半径），转动或指针移动时
与远景银河形成视差；它们由同一套时间输入驱动，不新建逐帧对象。

## 图层与材质

面片使用平面法线的 `MeshStandardMaterial`，保留深度测试、关闭深度写入，
透明度 0.016，配合主光/轮廓光作为可读的低多边形体积层（曾一度调到 0.028，
被「面积光量 < 10%」回归拦下）。主体由星尘表现，背景和辉光关闭深度测试，
按 `renderOrder` 绘制。渲染用轮廓丝带由三角网的边界边生成，包含孔洞；
原有内部网格数据继续保留供几何检查。

主粒子逐点带真实表面法线：`zodiac.js` 的 `vertexNormals()` 按三角面片面积
加权烘焙，并把 `z` 翻正（正面朝机位）；体积内粒子按深度翻转法线并插值到侧壁。
着色器用固定的世界空间主光 `uKeyDir`（随时间缓慢横扫）计算包裹 lambert、
一层背向补光与视线空间轮廓光。明暗只乘在颜色上、不乘 alpha，所以亮带扫过的
对比与「聚 → 停」亮度台阶保持既有回归值。近处粒子更大更实、深处更小更淡
（`vDepth`），加法混合下这才读得出前后层次。
造型微摆幅度约 ±0.54 rad（俯仰 ±0.19），侧视时正面与背面的亮度差让造型不再是「一张贴片」。

| renderOrder | 图层 | 构成 |
| --- | --- | --- |
| -1000 | 天空 | 近黑球面、预烘焙淡紫银河尘埃与暗带、暗角 |
| -900 / -890 / -880 | 背景 | 细密星场、星云柔斑、四芒星 |
| -100 | 形象图柔光 | 轮廓内低透明度点云 |
| -90 | 形象图面片 | 极低透明度的正面、背面及侧壁 |
| -82 / -80 | 轮廓边 | 仅外轮廓及孔洞的宽晕、细芯丝带 |
| -78 | 网格顶点 | 极弱辅助亮点 |
| -10 | 主粒子池 | 流动星尘、扫过主体的增辉带；八种汇聚/散开轨迹及方向拖尾 |
| 10 / 11 / 12 | 主星层 | 连线宽晕、白色细芯、四芒星及沿连线移动的光点 |

停留时主粒子透明度由窄亮带驱动：`wave = max(0, sin(x*1.6-time*3.1+seed*0.8))^12`，
透明度为 `0.448 + wave*1.12*motion`。亮带约每 2.03 秒扫过一次，保留 A 对比版的
空间连贯性和峰值对比，避免用轻微整体呼吸代替流光。点核更集中，外围为
指数衰减的柔光。面片透明度为 0.005，轮廓细芯为 0.28，宽晕为
0.075（随低频增辉），两层丝带宽度分别为 0.012 和 0.048。主星尺寸标量为 300；
网格顶点尺寸为 52，透明度仅为形象图显隐系数的 0.045 倍。柔光点尺寸标量为 120。
停留星尘进行小幅三维流动，全部由播放时间驱动；减弱动效将流动幅度降至 12%。
面片光量回归检查要求它贡献的亮度小于总画面的 10%。
每条主星连线另有一颗错峰移动的光点，周期为 5 秒，位置按原始连线的三维端点插值，
到端点时淡出再从起点淡入。移动光点并入现有主星几何及绘制层，不增加几何数量或渲染循环；
减弱动效将光点亮度降至 20%，显隐与主星共用生命周期。暂停时间会同时冻结亮带和移动光点。

`figureOpacity(state,k)` 统一驱动形象图和主星的显隐：汇聚后段浮现，散开前段
撤去，完全透明时跳过绘制。天空不随背景星云开关消失。

背景参考银河摄影：近黑底、密集细星、斜向淡紫色银河及不规则暗带。
低/中/高画质分别使用 6,000 / 16,000 / 28,000 颗背景细星，64% 沿银河带聚集。
这组点数与空间舞台的 12k/30k/50k points 预算对齐；星点尺寸略放大，用更少的点保持密度。
星点以白色为主，少量冷暖色，较大四芒星保持长尾分布，避免大光斑抢过主体。
星光用逐星随机相位、约 12–29 秒的缓慢周期改变亮度和光晕尺寸；四芒星在
呼吸峰值附近轻微增辉，错峰出现。减弱动效降低呼吸幅度，暂停时间保持画面确定。
流星层不挂在会跟随机位平移的背景组里，而是每帧复制相机位置与朝向，光痕位于
相机前方 18–52 单位的近/远两层。低/中/高画质预建 5 / 10 / 18 条，飞行 2.2–2.9 秒，
常规间隔按 2.8 秒错峰；每轮换座后的第 1–1.3 秒固定来一对双流星，正好叠在汇聚段后段，停住时仍看得到。
横竖屏用相机空间 x 轴缩放保持可见，暂停冻结、跳转重现；关闭背景星尘不会隐藏流星。
流星密度由场景参数 `meteors`（0–1.5，默认 1）控制，画质与密度只改变 draw range，
几何和材质交给现有 scope/销毁列表。银河尘埃使用周期 FBM 在挂载时烘焙到 512 / 1024 / 2048 宽的球面纹理，
细节不依赖球面顶点插值，也不逐帧运行全屏噪声。纹理、细星及柔斑共用银河
平面方向和缓慢旋转；天空与背景星场跟随机位平移。大部分天空保持近黑，
紫灰色只出现在银河带内，主题色及换座不染背景。纹理纳入 scope 或独立舞台的
销毁列表。主体颜色回归单独隐藏背景后测量，避免银河参与整幅图的色相统计。

`world.js` 的 `SIGN_COLORS` 按 `ZODIAC` 顺序定义主体和辉光两色：白羊珊瑚红、
金牛翡翠绿、双子香槟金、巨蟹月光银、狮子琥珀金、处女浅草绿、天秤玫瑰粉、
天蝎红紫、射手星云紫、摩羯青玉、水瓶冰蓝、双鱼淡紫。
切座同步更新面片、自发光、网格边、柔光、顶点、粒子与主星辉光，星芯保持白亮。
灯光采用接近中性的冷暖组合，避免青蓝灯光覆盖主体色。
共享点云颜色属性存中性明度，通过 uniform 乘各座颜色，不额外上传属性或创建材质。
自定义 shader 使用显示色，内置材质使用线性色；应用主题 accent 只少量混入高亮粒子，
不覆盖座次配色，不染背景。桌面/手机截图验证暖色、绿色、粉紫色均实际渲染。

`transitionStyle(cycle, sign)` 按周期和座次选择旋涡、纵深星流、波浪、轨道、放射、
螺旋、星雨及脉冲八种轨迹，汇聚和散开分别选择轨迹与旋转方向，同时改变错峰、
旋进速度和弧幅。同一座下一轮有不同组合，seek 仍然确定；错峰在生命周期两端
归一，确保所有粒子完整落位或散尽。
粒子错峰飞行、汇聚减速、散开加速，移动时使用沿屏幕速度方向的拉长光点。

## 机位、生命周期与资源

`main.js` 根据画幅比例、设计框和 `FRAME_MARGIN=1.30` 计算机位距离。
resize 重算适配距离但保留用户缩放；双击将 zoom 复位为 1。
距离上限随适配距离和最大缩放倍率延展，竖屏不会被桌面 18 单位上限裁切。
机位与造型按播放时间微摆，避免持续转到侧面后剪影变成一条线。
三维空间的指针移动会在 `root` 与近/中景星尘之间叠加约 0.12 / 0.28 单位的反向位移，
指针离开或减弱动效时回到零；拖拽时交给相机，不再叠加视差。

主星命中由 `screenStars()` 与 `pickStar()` 共用同一套相机投影：22px 半径内选最近星点。
悬停只改变主星材质的尺寸/亮度 uniform，点击在命中星点生成一圈脉冲环与 28 颗星火；
点击时如果指针位置与上一帧悬停位置一致，直接复用命中的主星，避免视差把点击甩出阈值。
读数卡由宿主 `space3d.js` 绘制，场景只通过可选的 `zodiacEvent` 回调上报
`sign / hover / select` 事件，不感知 DOM。

单座生命周期为 `2.8s gather → 7.6s hold → 2.6s disperse`，共 13 秒。
十二座预建几何并预热；新增星尘、脉冲与流星后 GPU 驻留仍保持恒定，纹理为 2（含银河尘埃）。
换座使用对应几何对象，不反复替换 BufferAttribute；unmount 统一销毁。
数据层缓存最多十二座，不含 GPU 对象。

背景在银河带附近加了一层极淡的极光帷幕，颜色只由时间与 `vUv` 决定，不随座次
变化（「大部分天空保持近黑」与「切座不染背景」两条像素回归继续成立）。

形象图新增三层倾斜星环、一块力场地面与一池轨道星尘。星环共享一张平面几何，
低/中/高画质分别显示 1/2/3 层；轨道星尘为 140/260/420 颗。星环关闭深度写入、
保留深度测试，写深度的体量面罩会挡住环的内侧，只在剪影外留下一圈光晕。
三层效果共用 `figureAlpha` 显隐：散开末段整组跳过绘制，背景恢复纯星空。
星环转速、轨道角速度与地面扫描都由场景时间驱动，seek 确定；减弱动效时
动画时钟归零、星环停在固定朝向。`stats()` 增加 `charge / surge / auraRings /
orbitPoints`，图层数 17 → 21。

交互层：独立舞台（stage3d）不再只把指针用于拖拽 —— 引擎自己维护
`localPointer`，悬停主星触发形变与读数事件，点击沿连线飞行光点增亮
（`uSurge`）。按住指针 0.85 秒充满蓄能：粒子被引力井吸向指针、星环收紧、
FOV 轻微收窄；松开按蓄能倍率放大冲击波，星链同时涌流。拖拽松手保留角速度，
双指捏合缩放；舞台适配层增加跟手能量准星 `.zodiac-reticle`，按住时变玫红
并旋转，关闭「交互旋转」立即隐藏。`Space3D` 的 `frame.pointer` 路径同形复用，
两套入口不需要分支。

## 修改时保留的约束

- 轮廓、网格、点云和主星共用一套坐标，不增加第二次星图归一化。
- 网格必须完整覆盖轮廓并保留孔洞，不能筛掉长三角形后留下断肢。
- 网格与主连线使用丝带；WebGL 的 LineBasicMaterial 无法提供可控线宽。
- 网格和粒子使用一致色彩管线，内置材质显式 `toneMapped:false`。
- 几何与 attribute 预建复用，切换十二座后资源数量必须保持有界。
- 造型数据改变后重跑面积覆盖、轮廓内采样、主星对齐和桌面/手机截图检查。
