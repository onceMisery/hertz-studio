# 皮肤设计稿：「潮汐」(chaoxi) v1.0

> 参考对象：腾讯 MOO 音乐 App 的皮肤体系
> 交付类型：设计稿（定位 / 视觉 / 色彩 / 排版 / 界面 / 主题 / Token / 生效范围）
> 说明：本文对 MOO 的归纳属于**设计视角的观察**，非其官方规范；所有数值为本方案自定的可执行值。

---

## 0. 一句话概览

**「潮汐」= 把界面退到最简，让专辑封面和文字成为主角。**
它是一套以「唱片 / 单曲聚焦」为隐喻、刻意低信息密度、动效只做确认不做表演的极简皮肤。

名字的来处：潮水一涨一落，中间那段时间是什么都没有的——这套皮肤卖的正是那段落差。
信息像潮水一样退下去，把滩涂留给封面和文字；该出现的东西再随下一次涨潮回来。
所以「留白」在本文里是**手法**（分区靠留白、页脚留白），「潮汐」是**名字**。

在本项目既有的 6 套皮肤里，它的空位如下：

| 皮肤 | id | 主导隐喻 | 信息密度 | 与「潮汐」的关系 |
|---|---|---|---|---|
| 经典 | `classic` | 三栏工作台 | 中 | 基线 |
| 浮光 | `sheen` | 悬浮胶囊 + 全宽网格 | 中高 | 对照：潮汐不做网格堆叠 |
| 工作台 | `workbench` | 直角细线、数据面板 | 高 | 对照：潮汐刻意减密度 |
| 流年 | `liunian` | 暖调播放卡 + 凝彩舞台 | 中 | 对照：潮汐不做暖调装饰 |
| OS风 | `ios` | 侧栏 + 分组列表 | 中高 | 对照：潮汐不靠分组容器 |
| 清风 | `qingfeng` | 全宽海报墙 | 高 | 对照：潮汐不做封面墙 |
| **潮汐** | **`chaoxi`** | **唱片 / 单曲聚焦** | **低（刻意的）** | — |

## 1. 设计定位与目标用户

### 1.1 定位

一句话定位：**内容优先的单曲聚焦式极简皮肤**。

三条定位边界（用来在评审时快速判断"该不该加"）：

1. 屏幕上任何元素，如果不能帮用户「开始听」或「找到想听的」，默认不出现。
2. 同一时刻，封面是唯一的彩色来源；UI 本身保持单色。
3. 动效的合法性来自「回答用户刚才做了什么」，不是来自「好看」。

### 1.2 目标用户

| 画像 | 特征 | 核心诉求 | 本方案回应 |
|---|---|---|---|
| **静听者**（22–32，独处通勤 / 深夜） | 一次听一张专辑，不愿被打断 | 沉浸、少打扰 | 播放页文字元素 ≤ 6；舞台全屏覆盖，导航自动隐退 |
| **收藏者**（有整理歌单习惯） | 歌单 20+，在意封面与排序 | 视觉秩序、封面可读 | 封面尺寸放大到基线的 1.6×；列表靠留白 + 1px 细线分隔 |
| **轻量用户**（日均 10–30 分钟） | 打开就要听，不逛 | 三步内开始播放 | 发现页首屏首卡即「继续播放」；播放全部按钮常驻分区标题行 |

### 1.3 可验收的设计目标

| 目标 | 判据 |
|---|---|
| 三步内开始播放 | 冷启动 → 播放按钮的点击数 ≤ 3 |
| 播放页不嘈杂 | 播放页可见文字元素 ≤ 6 个 |
| 强调色克制 | 同一视口内强调色出现 ≤ 1 处（正在播放指示不计入） |
| 动效不拖沓 | 所有 UI 过渡 ≤ 320ms（唱片旋转是持续状态，不在此列） |
| 留白可感知 | 分区间距 ≥ 32px，内容区左右留白 ≥ 24px |

### 1.4 非目标（明确不做）

- 不做第二套信息架构：沿用现有导航语义与页面集合，只换呈现方式。
- 不做自定义配色：颜色一律由主题层提供，皮肤只提供色槽与用色规则。
- 不做新的播放能力：切歌 / seek / 收藏全部走既有业务路径。

## 2. 整体视觉风格与设计理念

四条理念，每条都附一条**可执行的判据**，避免它们停留在口号。

### 理念一：留白不是空，是节奏

用空白和字号差分隔层级，而不是靠描边卡片和分割线。

- **判据**：同一屏内卡片描边（border）出现次数 ≤ 2；分隔优先用间距，其次用 1px `--line`。
- MOO 的启发：它的首页几乎看不到"卡片"，卡片感是由留白挤出来的。

### 理念二：一张封面就是一屏的视觉锚点

封面是这套皮肤里唯一允许全彩、唯一允许大面积的元素。

- **判据**：主封面（播放页唱片 / 歌单详情头图）的短边 ≥ 208px，是基线卡片封面的 1.6×。
- 其余所有图形一律单色（文字色 / 强调色 / 铜色点缀）。

### 理念三：细线而非卡片

用 1px 分隔线 + 悬停底色代替"每张卡都有描边 + 阴影"的做法。

- **判据**：列表行在默认态**没有**描边、**没有**阴影；层级靠背景 `--hover` 与 `--panel-2` 表达。
- 浅色主题尤其重要：浅底上描边和阴影都容易脏，靠留白最干净。

### 理念四：动效只做「确认」，不做「表演」

每次动效必须能回答"我点了什么"或"它现在在哪"。

- **判据**：任何动效都能写成一句话说明其语义（例：卡片 `scale(0.985)` = "我按住了它"）。
  写不出来的动效一律删掉。
- 唯一的例外是唱片旋转——它是**状态指示**（在播 / 停了），不是装饰。

## 3. 主色调与辅助色

### 3.0 先说分层：皮肤不写颜色

本项目的外观是三层分离的（主题管颜色 / 皮肤管布局 / 舞台主题管沉浸层）。
因此「潮汐」皮肤本身**不携带颜色字面量**，它携带的是：

1. 一组**色槽**（semantic slot）——皮肤只写 `var(--brand)`，不写 `#C8A96A`；
2. 一条**用色规则**（见 3.3）——规定每个色槽在界面上出现几次、出现在哪。

下面 3.1 / 3.2 的色板，是配套主题「潮汐·昼 / 潮汐·夜」的**推荐取值**，供主题层落地时直接采用。

### 3.1 深色基准色板（潮汐·夜）

| 令牌 | 十六进制 | 用途 |
|---|---|---|
| `--bg` | `#0E0E10` | 页面底色（不用纯黑，见 7.3） |
| `--panel` | `rgba(24, 24, 27, 0.78)` | 玻璃面板 |
| `--panel-solid` | `#18181B` | 不透明面板（弹层、菜单） |
| `--panel-2` | `rgba(255, 255, 255, 0.045)` | 次级填充、骨架屏底 |
| `--line` | `#1F2023` | 分隔线 |
| `--line-strong` | `#2C2D31` | 唱片外圈、强分隔 |
| `--text` | `#EDEDF0` | 主文字（对比度 ≈ **16.5:1**） |
| `--muted` | `#92949B` | 次要文字（≈ **6.4:1**） |
| `--accent` | `#E8E6E1` | 强调（近白，不用纯白） |
| `--accent-2` | `#C8A96A` | 铜色点缀（≈ **8.6:1**） |
| `--brand` | `#C8A96A` | **正在播放 / 生效中** |
| `--brand-ink` | `#0E0E10` | 铜色底上的前景色 |
| `--highlight` | `#E8E6E1` | **当前选中** |
| `--hover` | `rgba(255, 255, 255, 0.06)` | 悬停 / 按下底色 |

语义色（深色档，比浅色档整体提亮一档）：

| 语义 | 深色 | 说明 |
|---|---|---|
| 成功 / 已收藏 | `#4CAF6D` | 只在图形与短标签上使用 |
| 警告 | `#E08A3C` | |
| 危险 / 删除 | `#E5484D` | 退出登录、删除歌单 |
| 链接 | `#6EA8FE` | |

### 3.2 浅色基准色板（潮汐·昼）

| 令牌 | 十六进制 | 用途 |
|---|---|---|
| `--bg` | `#F7F6F4` | 暖白纸感底（对应 MOO 日间模式） |
| `--panel` | `rgba(255, 255, 255, 0.78)` | 玻璃面板 |
| `--panel-solid` | `#FFFFFF` | 不透明面板 |
| `--panel-2` | `rgba(20, 20, 22, 0.035)` | 次级填充、骨架屏底 |
| `--line` | `#E4E2DE` | 分隔线 |
| `--line-strong` | `#D2CFCA` | 强分隔 |
| `--text` | `#16171A` | 主文字（≈ **16.6:1**） |
| `--muted` | `#6B6E76` | 次要文字（≈ **4.7:1**） |
| `--accent` | `#16171A` | 浅色下强调色**反过来是墨色** |
| `--accent-2` | `#A98244` | 铜色（图形用，≈ 3.3:1） |
| `--brand` | `#A98244` | 正在播放（图形） |
| `--brand-ink` | `#8A6A33` | **铜色文字专用**（≈ **4.6:1**） |
| `--highlight` | `#16171A` | 当前选中 |
| `--hover` | `rgba(20, 20, 22, 0.05)` | 悬停 / 按下底色 |

> ⚠️ **铜色在浅色下必须分两档**：`#A98244` 只够 3:1，仅可用于图形、描边、指示条；
> 一旦要承载文字，必须换 `--brand-ink` `#8A6A33`（4.6:1）。这是本方案里最容易漏的一条。

### 3.3 用色规则（皮肤层的"色槽纪律"）

| # | 规则 |
|---|---|
| R1 | 同一视口内 `--brand` 出现 **≤ 1 处**（正在播放指示是唯一例外，且它必须与 brand 同源） |
| R2 | 播放态用 `--brand`，选中态用 `--highlight`，**不得互换**（历史上最容易混的一对） |
| R3 | 进度 / 音量：轨道用 `--track`，已走过的部分用 `--brand`，把手用 `--text` |
| R4 | 封面是全屏唯一允许"彩色"的元素；UI 层一律单色 |
| R5 | 分隔线在深色下要比底色**亮 12%**（暗底上暗线看不见），浅色下反过来压暗 |
| R6 | 禁止用颜色单独传达状态——颜色必须搭配图标、文字或位置（无障碍） |

## 4. 字体与排版规范

### 4.1 字体族

```
中文： "PingFang SC", "HarmonyOS Sans SC", "Microsoft YaHei", sans-serif
拉丁： "Inter", "SF Pro Text", system-ui, sans-serif
数字： 沿用拉丁族 + font-variant-numeric: tabular-nums
```

- **数字必须等宽**：时间码 `03:41 / 02:58`、曲目序号、播放计数，一旦用比例数字，
  进度跳秒时整行会左右抖动。`tabular-nums` 是硬要求，不是优化项。
- 不引入衬线体：MOO 的克制感来自字重与留白，不是字体性格。

### 4.2 字阶（映射到 `--skin-h*` 排版令牌）

| 令牌 | 字号 / 行高 | 字重 | 字距 | 用途 |
|---|---|---|---|---|
| `--skin-h1` | 34 / 42 | 600 | −0.02em | 页标题（发现 / 个人中心） |
| `--skin-h-album` | 28 / 36 | 600 | −0.015em | 播放页曲名 |
| `--skin-h2` | 20 / 28 | 600 | −0.01em | 分区标题、歌单名 |
| `--skin-h3` | 16 / 24 | 500 | 0 | 卡片标题、列表主行 |
| `--skin-h4` | 14 / 20 | 500 | 0 | 次级行标题 |
| `--skin-body` | 14 / 22 | 400 | 0 | 正文 |
| `--skin-caption` | 12 / 16 | 400 | 0 | 辅助信息、时间戳 |
| `--skin-time` | 12 / 16 | 400 | 0 | 时长（强制 tabular-nums） |

> 落地提醒：这些令牌的**默认值必须等于改前 px**，否则默认皮肤会跟着变。
> 「潮汐」只能在自己的 `[data-skin="chaoxi"]` 作用域内覆盖。

### 4.3 排版纪律

- 层级靠**字号 + 字重 + 灰度**三者中选**两个**表达，不要三样齐上（会显得用力过猛）。
- 全大写拉丁文本（如 `PLAY ALL`）字距 `+0.08em`。
- 中文标题字距为负（−0.01 ~ −0.02em），中文正文为 0。
- 截断规则：曲名 / 歌单名 1 行省略；艺人名 1 行省略；专辑名 ≥1024px 才显示。
- 数字与单位间留 4px；中英文交界处不留额外空格（用 CSS `text-autospace` 或手工处理）。

## 5. 图标与插画风格

### 5.1 图标

| 项 | 规范 |
|---|---|
| 网格 | 24×24，安全区 2px（内容落在 20×20 内） |
| 描边 | **1.6px**（视觉 2px），圆端头（`stroke-linecap: round`），圆角接头 |
| 填充 | 默认**无填充**；仅 3 个例外：播放（实心三角）、暂停（实心双竖）、喜欢（实心心形） |
| 尺寸档 | 16（行内）/ 20（工具栏）/ 24（默认）/ 32（空态装饰）/ 56（主播放钮内的图形） |
| 颜色 | 一律继承 `currentColor`，不写死颜色 |
| 语义一致 | 同一语义全站一个图形，不得为美观换图标（换肤后用户需要重新学习） |

### 5.2 插画

- **风格**：单色线稿 + 单一铜色点缀（点缀占比 ≤ 10% 面积）。
- **线宽**：1.6px，与图标同粗；**无渐变、无阴影、无 3D**。
- **尺寸**：空态插画 96×96（居中，上方间距 48，下方说明间距 24）。
- **动效**：允许一条 ≤ 600ms 的循环微动（如唱针轻摆 ±4°），`prefers-reduced-motion` 下停。

需要的 4 幅空态插画：

| 场景 | 画面 |
|---|---|
| 收藏 / 歌单空 | 空唱片架（三道横向沟槽，中间一层空着） |
| 搜索无结果 | 放大镜 + 一张被划过的唱片沟槽 |
| 歌单无曲目 | 空唱盘（中心标签留白） |
| 离线 / 加载失败 | 断线的唱针 + 静止的唱片 |

### 5.3 封面处理

- 圆角统一 `--radius-md`（12），歌单详情头图用 `--radius-lg`（16）。
- **不做投影当分隔**：深色下投影看不见，浅色下投影显脏。改用 `0 0 0 1px var(--line)` 描边。
- 加载中的封面：底色 `--panel-2` + 中心一个 24px 唱片线稿（不用 spinner）。

## 6. 核心界面设计

### 6.0 全局骨架（先定骨架，再谈页面）

```
┌──────────────────────────────────────────────────────────┐
│ #rail 72px │            内容区（max 1080，居中）            │
│ 图标+竖排  │  ── 左右 --skin-gap：40 / 24(≤900) / 16(≤620) │
│ 文字标签   │                                               │
│            │                                               │
├────────────┴──────────────────────────────────────────────┤
│ #bar 迷你播放条 高 72（内容盒内四周 16 padding）             │
└──────────────────────────────────────────────────────────┘
         舞台 .s3d：全屏覆盖层（z 60），播放页进入时淡入
```

| 层 | z-index | 备注 |
|---|---|---|
| 内容 | 0 | |
| `#rail` 侧轨 | 20 | 可折叠为 56px（只留图标） |
| `#topbar` | 40 | 常驻，滚动时压缩为 48px |
| 舞台覆盖层 | 60 | 「潮汐」特有：从抽屉改为全屏 |
| 弹层 / 菜单 | 80 | **必须挂 `body`** |
| Toast | 100 | |

> ⚠️ **层叠上下文坑**：`#topbar` 同时有 `z-index` 与 `backdrop-filter`，双重形成层叠上下文，
> 它的子节点无论写多高 z-index 都压不过 body 层里 z=60 的舞台覆盖层。
> 所有弹层（搜索建议、皮肤菜单、曲目更多菜单）**一律 `appendChild` 到 `body`**。
> 症状是"点了没反应、控制台干净"，排查成本极高，所以写进规范。

### 6.1 发现页 / 推荐歌单

#### 布局层级（自上而下）

| # | 区块 | 高度 / 栅格 |
|---|---|---|
| 1 | 页头：h1「今日」+ 日期 + 右侧搜索入口 | 88 |
| 2 | 「每日 30」横向唱片架 | 卡片 168 封面 + 2 行文字，横向 scroll-snap |
| 3 | 分区标题 + 推荐歌单网格 | 3 列 / 2 列(≤900) / 1 列(≤620)，封面 1:1 |
| 4 | 「最近播放」单列细线列表 | 行高 64，1px `--line` 分隔 |
| 5 | 页脚留白 | 96 |

#### 关键组件位置

- **搜索入口**：页头右端，圆角胶囊，宽 240（≤620 时收成 40 的图标钮）。
- **「播放全部」**：在每个分区标题行**右端**，图标 + 文字，用 `--brand` 作主色。
- **卡片悬浮播放钮**：封面右上角内侧 12px 处，直径 40，默认 `opacity:0`。
- **继续播放卡**：第 2 区块的首位固定为「继续播放」，封面右下角叠一条 3 柱音柱（正在播放指示）。

#### 交互状态

| 状态 | 表现 |
|---|---|
| 默认 | 封面无描边（靠留白分隔）；文字 2 行截断；悬浮播放钮 `opacity:0` |
| 悬停 | 整卡背景 `--hover`；播放钮 `opacity:0→1`（160ms）+ `scale(.9→1)`；封面 `scale(1.02)` |
| 按下 | 卡片 `scale(0.985)`；播放钮 `scale(0.94)`；120ms |
| 加载 | **骨架屏**：封面 = `--panel-2` 底色 + 1 条 shimmer（1.2s 循环，扫过 120% 宽）；文字 = 2 条圆角占位（高 12/10，宽 70%/45%）。**不用 spinner** |
| 空态 | 96×96 插画 + 1 行说明（14/22，`--muted`）+ 1 个次要按钮 |
| 错误 | 插画 + 说明 + 「重试」主按钮（带 `[aria-live]` 播报） |

#### 交互动效

- 卡片入场：`opacity 0→1` + `translateY(8→0)`，stagger **40ms**，240ms `--ease-out`。
- 横向唱片架：`scroll-snap-type: x proximity`，惯性停止后吸附；两端各留 40 的"呼吸位"。
- 切页：内容区 `opacity 0→1` 180ms，**不做位移**（潮汐皮肤的切换应该安静）。

### 6.2 播放页（本皮肤的主场）

#### 布局：一个三行的定高 flex 列

```
┌────────────────────────────────────────────┐

└────────────────────────────────────────────┘
```

唱片细节：

- 直径 480（≤900 时 320，≤620 时 260），外圈 `1px var(--line-strong)` 描边。
- 沟槽：`repeating-radial-gradient`，相邻两道亮度差 **≤ 4%**（再大就出摩尔纹）。
- 中心标签 = 封面圆形裁剪，直径 = 唱片的 33%（480 → 160）。
- 唱针：右上角 45° 斜插，默认落在唱片上；暂停时抬起 12°。

#### 关键组件位置

| 组件 | 位置 | 规格 |
|---|---|---|
| 进度条 | 顶栏下方整宽 | 轨道 4px / 圆角 2；已播放 `--brand`；把手 12px 圆点（默认 `opacity:0`） |
| 时间码 | 进度条左右两端 | `--muted`，tabular-nums |
| 主控制组 | 居中 | 顺序：上一首(40) / **播放(56)** / 下一首(40)，间距 24 |
| 次控制组 | 主控制组下方一行，两端对齐 | 左：循环、喜欢；右：音量、歌词 |
| 歌词 | 底部，默认 3 行预览 | 当前行 `--text` 600；非当前行 `--muted` 400 + `opacity:.55`；当前行左侧 2px `--brand` 竖条 |

#### ⚠️ 定高 flex 列的硬纪律

歌词区是**唯一的滚动区**：

```css
.lyrics { flex: 1 1 auto; min-height: 0; overflow-y: auto; }
.title, .artist, .album, .progress, .controls { flex: none; }
```

不这么写的后果：定高 flex 列里**最后一个可收缩项会被压扁**，而它报出来的 `fontSize`
仍是原值——只看字号永远发现不了，必须量 `getBoundingClientRect().height`。
历史上给歌词区兜了 `min-height` 之后，缺口会**转嫁**给曲名（33px→14px），问题只是搬家。

#### 交互状态

| 状态 | 表现 |
|---|---|
| 默认（播放中） | 唱片 `spin 20s linear infinite`；唱针落下 |
| 暂停 | 唱片在 1.6s 内**减速停在当前角度**（不能用 `animation-play-state`，要自定义减速曲线）；唱针抬起 12° |
| 按下 | 主播放钮 `scale(0.94)`，160ms |
| 加载（切歌 / 缓冲） | 唱片继续转但 `opacity → .45`；进度条进入**不确定态**（轨道内一条 30% 宽的 `--brand` 块来回平移，1.1s 循环）；控制按钮除跳转类外保持可点 |
| 空态（无歌词） | 歌词区显示「纯音乐，请欣赏」+ 一条 60px 静态波形线稿 |
| 拖动进度 | 把手放大到 16px；时间码旁浮出气泡显示目标时间；松手后 200ms 淡出 |

#### 交互动效

- 进入播放页：舞台覆盖层 `opacity 0→1` 240ms；唱片从 `scale(.92)` 到 1，320ms `--ease-out`。
- 歌词换行：当前行 `translateY(6→0)` + `opacity`，220ms；整体位移用 `transform`，**不用 `scrollTop` 硬跳**。
- 唱片旋转**必须可关**：设置项「减少动态效果」开启时停转，改静态封面，唱针保持落下。
- `prefers-reduced-motion` 同上一档。

## 7. 深浅色双主题适配方案

### 7.1 四条适配原则

1. **皮肤层不写颜色字面量**。深浅完全由主题层提供，皮肤只提供色槽与用色规则（第 3 节）。
2. **深浅不是"反色"，是"重排光的来源"**：
   - 深色 = 光从封面来（UI 是暗的，封面是唯一亮的）
   - 浅色 = 光从环境来（UI 是亮的，封面靠自身色彩站立）
3. **浅色必须自带玻璃令牌覆盖**：`--glass-border` / `--glass-line` / `--glass-bg` /
   `--surface-*` / `--field-*` / `--track` / `--hover`。
   本项目的玻璃体系是**为暗底写的**，翻到浅底后白色叠层 = 白叠白，描边 / 轨道 / 悬停会全部消失。
4. **别一刀切禁白**：`--panel` / `--surface-1` / `--glass-line` 在浅色下**本就该是白的**；
   只有**分隔类**令牌（`--line` / `--line-strong`）必须压暗。

### 7.2 关键令牌的深浅对照

| 令牌 | 深色 | 浅色 | 变化逻辑 |
|---|---|---|---|
| `--bg` | `#0E0E10` | `#F7F6F4` | 换底 |
| `--panel` | `rgba(24,24,27,.78)` | `rgba(255,255,255,.78)` | 叠层方向反转 |
| `--panel-2` | `rgba(255,255,255,.045)` | `rgba(20,20,22,.035)` | 叠加物反转 |
| `--line` | `#1F2023`（比底亮） | `#E4E2DE`（比底暗） | **方向相反**，不是同一套值 |
| `--text` | `#EDEDF0` | `#16171A` | 换墨 |
| `--muted` | `#92949B` | `#6B6E76` | 都需 ≥ 4.5:1 |
| `--accent` | `#E8E6E1`（近白） | `#16171A`（墨） | **反转**，不是同一个色相 |
| `--brand` | `#C8A96A` | `#A98244` | 压深一档保 AA |
| `--brand-ink` | `#0E0E10` | `#8A6A33` | 承载文字的那档，浅色下必须单独给 |
| `--hover` | `rgba(255,255,255,.06)` | `rgba(20,20,22,.05)` | 反转 |

### 7.3 暗黑模式（深色主题）专项表现

| 议题 | 处理 |
|---|---|
| 底色 | 用 `#0E0E10` 而非纯黑 `#000`：纯黑在 OLED 上边界过硬、易出现涂抹感，且让"层级"无处表达 |
| 玻璃不透明度 | 面板从常规 .72 提到 **.78**——暗底需要更强的"面"来撑起层级 |
| 强调色 | 用 `#E8E6E1` 而非 `#FFF`：纯白在深色底上会产生光晕（尤其细字） |
| 封面"投影" | 暗底上投影看不见 → 改成**外发光 + 描边**：`0 0 0 1px var(--line), 0 24px 60px rgba(0,0,0,.6)` |
| 唱片沟槽 | `repeating-radial-gradient`，相邻亮度差 ≤ 4%，否则大面积同心圆出摩尔纹 |
| 分隔线 | 必须比底色**亮**（提约 12%），暗底上暗线等于没有 |
| 封面叠层 | 深色下**不要**给封面加 4% 白色叠层（会显脏）；浅色下也不要 |
| 图像降噪 | 小尺寸封面（<80px）在深色下加 1px `--line` 描边，防止与背景糊在一起 |

### 7.4 自动切换与降级

- 默认跟随系统 `prefers-color-scheme`；用户一旦手动选过，以手动值为准（持久化键沿用既有主题键）。
- 切换时机：在 `visibilitychange` 回到前台时补一次检查（用户可能在系统设置里改了）。
- **降级**：不支持 `color-mix()` 的环境，由主题层提供**预计算好的**降级值，
  不在运行时现场算——否则老环境里所有半透明派生色会一起塌成透明。

## 8. Design Token

> 结构令牌（圆角 / 间距 / 动效）**不进主题表**。换主题只换颜色，不换布局。

### 8.1 圆角

| 令牌 | 值 | 用途 |
|---|---|---|
| `--radius-xs` | 4 | 标签、芯片 |
| `--radius-sm` | 8 | 按钮、输入框 |
| `--radius-md` | 12 | 卡片、封面 |
| `--radius-lg` | 16 | 大卡、歌单头图、分组容器 |
| `--radius-pill` | 999 | 搜索框、主播放钮、芯片 |
| `--radius-record` | 50% | 唱片、头像 |

纪律：「潮汐」整体比基线大 4px，但**任何圆角不得超过 20px**——超过就与"克制"冲突。

### 8.2 间距（8 为基准，允许 4 的半步）

| 令牌 | 值 | 用途 |
|---|---|---|
| `--sp-1` | 4 | 图标与文字之间 |
| `--sp-2` | 8 | 芯片间隙、紧凑对齐 |
| `--sp-3` | 12 | 卡片内边距（紧凑档） |
| `--sp-4` | 16 | 卡片内边距（标准档）、行内边距 |
| `--sp-5` | 24 | 组内间距 |
| `--sp-6` | 32 | 分区间距 |
| `--sp-7` | 48 | 大分区间距、空态上方留白 |
| `--sp-8` | 96 | 页脚留白 |

内容区左右 `--skin-gap`：**40 / 24（≤900px） / 16（≤620px）**。

### 8.3 尺寸

| 项 | 值 |
|---|---|
| 行高 | 列表 56 / 卡片列表 64 / 头部 88 / 顶栏 64（滚动后压缩 48） |
| 触控目标 | 最小 44×44（图标按钮靠 padding 撑够，不靠放大图标） |
| 封面 | 唱片架 168 / 歌单卡 1:1 自适应 / 详情头图 208 / 播放页唱片 480（320@≤900，260@≤620）/ 迷你条 48 |
| 播放钮 | 主 56 / 次 40 / 卡内浮出 40 |
| 侧轨 | 72（折叠 56） |
| 内容区 | max-width 1080，居中 |

### 8.4 层级与阴影

深色：

```
--shadow-1: 0 2px 8px rgba(0,0,0,.40)
--shadow-2: 0 12px 32px rgba(0,0,0,.55)
--shadow-3: 0 24px 64px rgba(0,0,0,.70)
```

浅色（更淡、更散，且**靠描边而非阴影**分隔）：

```
--shadow-1: 0 2px 8px rgba(20,20,22,.06)   + 0 0 0 1px var(--line)
--shadow-2: 0 12px 32px rgba(20,20,22,.10) + 0 0 0 1px var(--line)
--shadow-3: 0 24px 64px rgba(20,20,22,.14) + 0 0 0 1px var(--line)
```

z-index：内容 0 / rail 20 / topbar 40 / 舞台 60 / 弹层 80 / toast 100（弹层挂 `body`）。

### 8.5 动效

| 令牌 | 值 | 用途 |
|---|---|---|
| `--ease-out` | `cubic-bezier(.22,.61,.36,1)` | 默认出场 |
| `--ease-spring` | `cubic-bezier(.34,1.40,.64,1)` | 弹入 / 回弹（克制使用） |
| `--dur-fast` | 120ms | 按下反馈 |
| `--dur-base` | 200ms | 悬停、展开 |
| `--dur-slow` | 320ms | 页面切换、覆盖层 |
| `--dur-spin` | 20s | 唱片转一圈（**持续状态，不是过渡**） |
| `--dur-shimmer` | 1.2s | 骨架屏扫光（循环） |

纪律：

- **上限 320ms**，任何 UI 过渡不得更慢。
- `prefers-reduced-motion: reduce` → 所有过渡降到 1ms、stagger 取消、**唱片停转**。
- 循环动画（shimmer / spin / 音柱）必须在页面不可见时暂停（`visibilitychange`）。

## 9. 切肤生效范围

### 9.1 ✅ 皮肤负责（切到「潮汐」会变）

- **布局骨架**：侧轨宽度、栅格列数、卡片尺寸、行高、留白节奏
- **组件位置**：控制组的顺序、按钮在标题行的哪一端、封面尺寸档位
- **密度与断点**：3 / 2 / 1 列的切换断点（1440 / 900 / 620）
- **舞台呈现方式**：是右侧抽屉还是全屏覆盖层
- **排版字阶**：只在 `[data-skin="chaoxi"]` 作用域内覆盖 `--skin-h*`

### 9.2 🎨 主题负责（换主题会变，换皮肤不变）

- 全部颜色，含深浅两套
- 玻璃质感参数（模糊半径、叠层不透明度）

### 9.3 ⚙️ 业务层负责（所有皮肤共享，皮肤不得重写）

- 播放 / 暂停 / 切歌 / seek / 音量 / 收藏的全部逻辑
- 歌单与曲库数据、搜索召回与排序
- 设置项本体、账号与登录态
- 「每日推荐折叠」按钮（业务层已有，换皮肤自动获得，不要按皮肤各写一遍）

### 9.4 落地时的三条硬约束（最容易踩）

1. **皮肤 CSS 里不得出现颜色字面量**——连 `rgba(0,0,0,.5)`、`#000` 都不行；
   阴影必须走 `--shadow-*` 令牌，不能用裸 rgba。
2. **皮肤 CSS 里不得出现交互状态选择器**（`:hover` / `:active` / `:focus` / `:disabled`）——
   状态样式由主题层 / 基础层统一，否则换主题后状态表现会漂移。
3. **皮肤把业务节点钉成非默认 `display` 后，`hidden` 属性会失效**
   （皮肤选择器特异性压过 UA 的 `[hidden]`）。
   收起 / 隐藏一律用**皮肤自己的类 + `display:none !important`**。

### 9.5 切换与持久化（沿用既有机制，本方案不改）

| 环节 | 行为 |
|---|---|
| 切换顺序 | 卸载旧布局 → 更新 `data-skin` 与 CSS → 挂载新布局 → 广播 `skin:changed` |
| 持久化 | `vmusic.skin` = `chaoxi` |
| 两个宿主 | 设置页卡片列表 + 顶栏弹层，切完**两处都要重画**（否则一处高亮 A、一处高亮 B） |
| 缺 CSS | 回落 `classic` 并 `console.warn`（**不静默失败**——静默失败最难查） |
| 重排通知 | 舞台画布 / 3D 场景靠 `skin:changed` 自行按新尺寸重排，不在切肤逻辑里硬编码谁要重画 |
| 生命周期 | 若有 mount/unmount，走 `registerLifecycle('chaoxi', {...})`；卸载时临时状态必须摘干净，且摘在 `restoreMoves()` **之前** |

### 9.6 接线清单（4 处，缺一处症状各不相同）

| # | 动作 | 缺失症状 |
|---|---|---|
| 1 | `skins/skins.js` CATALOG 增一行 | 设置列表里根本看不到这套皮肤 |
| 2 | `index.html` 加 `<link data-skin-css="chaoxi" disabled>`，**位置在 `style.css` 之后** | 位置错 → 规则被基础层盖掉；缺失 → 切过去没反应 |
| 3 | `index.html` 加 `<script>`，**在 `skins.js` 之后、`app.js` 之前** | 不监听 `skin:changed` |
| 4 | 资源清单登记 CSS / JS 文件 | 线上还是旧的 |

## 10. 验收清单

**设计与体验**

- [ ] 冷启动 → 开始播放的点击数 ≤ 3
- [ ] 播放页可见文字元素 ≤ 6 个
- [ ] 同一视口内 `--brand` 出现 ≤ 1 处
- [ ] 所有 UI 过渡 ≤ 320ms
- [ ] 深色 / 浅色各跑一遍对比度：正文 ≥ 4.5:1，次要文字 ≥ 3:1
- [ ] 铜色文字在浅色下用的是 `#8A6A33`，不是 `#A98244`
- [ ] 4 幅空态插画就位（收藏 / 搜索 / 歌单 / 离线）
- [ ] 骨架屏不使用 spinner
- [ ] `prefers-reduced-motion` 下唱片停转、stagger 取消
- [ ] 断点 1440 / 1024 / 900 / 620 / 390 各截一次图

**规范合规**

- [ ] 皮肤 CSS 零颜色字面量
- [ ] 皮肤 CSS 零交互状态选择器
- [ ] 隐藏/收起未依赖 `hidden` 属性
- [ ] 所有弹层挂在 `body` 下
- [ ] 定高列里歌词区是唯一滚动区，其余 `flex:none`
- [ ] 切肤后设置页列表与顶栏弹层高亮一致

## 附：与 MOO 皮肤体系的对应关系

| MOO 的做法（设计视角观察） | 本方案的转译 | 为什么这样转译 |
|---|---|---|
| 极简、大留白，首页几乎看不到卡片 | 用留白与字号差分层级，描边 ≤ 2 处 | 保留气质，但本项目需要可扫读的列表 |
| 黑胶 / 唱片机隐喻贯穿播放页 | 480 唱片 + 唱针 + 沟槽，旋转 = 播放状态 | 隐喻直接可感知；并给出"可关闭"开关 |
| UI 单色 + 极少量强调色 | 墨色基底 + 单一铜色点缀 | 铜色比 MOO 的纯黑白更耐看，且能承载"正在播放"语义 |
| 动效克制 | 全部过渡 ≤ 320ms，动效需能一句话说明用途 | 把"克制"变成可验收的数值 |
| 卡片式、封面为主角 | 封面尺寸放大到基线 1.6×，UI 单色 | 强化锚点，同时避免整屏彩色打架 |
| 日间 / 夜间双模式 | 深浅两套主题，且强调色在浅色下**反转为墨色** | 直接反色会破坏 AA，必须重排而非反转 |
| 皮肤可切换 | 沿用既有 `data-skin` 机制，皮肤只管布局 | 与本项目三层分离架构对齐 |
