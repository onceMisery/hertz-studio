Skin Design Spec · v1.0 · 参考腾讯 MOO 音乐皮肤体系

潮汐chaoxi

把界面退到最简，让专辑封面和文字成为主角。 一套以「唱片 / 单曲聚焦」为隐喻、刻意低信息密度、动效只做确认不做表演的极简皮肤。

名字的来处：潮水一涨一落，中间那段时间是什么都没有的—— 这套皮肤卖的正是那段落差。信息像潮水一样退下去，把滩涂留给封面和文字； 该出现的东西再随下一次涨潮回来。所以「留白」是手法，「潮汐」是名字。

4 · 图标与插画

1.6px 圆端描边 · 无填充（3 个例外）· 单色线稿 + 单一铜色点缀

项规范
网格24×24，安全区 2px（内容落在 20×20 内）
描边1.6px（视觉 2px），stroke-linecap: round，圆角接头
填充默认无填充；仅 3 个例外：播放（实心三角）、暂停（实心双竖）、喜欢（实心心形）
尺寸档16 行内 / 20 工具栏 / 24 默认 / 32 空态装饰 / 56 主播放钮图形
颜色一律 currentColor，不写死颜色
插画单色线稿 + 铜色点缀（≤ 10% 面积）；线宽 1.6px；无渐变、无阴影、无 3D
空态 4 幅空唱片架（收藏空）· 放大镜 + 唱片沟槽（搜索无果）· 空唱盘（歌单无曲目）· 断线唱针（离线）
插画动效允许 ≤ 600ms 循环微动（唱针轻摆 ±4°）；prefers-reduced-motion 下停
封面处理：不做投影当分隔。深色下投影看不见，浅色下投影显脏 —— 统一改用 0 0 0 1px var(--line) 描边。

6 · 深浅色双主题适配

深浅不是「反色」，是重排光的来源

令牌深色浅色变化逻辑
--bg#0E0E10#F7F6F4换底
--panelrgba(24,24,27,.78)rgba(255,255,255,.78)叠层方向反转
--panel-2rgba(255,255,255,.045)rgba(20,20,22,.035)叠加物反转
--line#1F2023（比底亮）#E4E2DE（比底暗）方向相反，不是同一套值
--text#EDEDF0#16171A换墨
--muted#92949B#6B6E76都需 ≥ 4.5:1
--accent#E8E6E1（近白）#16171A（墨）反转，不是同一色相
--brand#C8A96A#A98244压深一档保 AA
--brand-ink#0E0E10#8A6A33承载文字的那档，浅色下必须单独给
--hoverrgba(255,255,255,.06)rgba(20,20,22,.05)反转

暗黑模式专项

议题处理
底色用 #0E0E10 而非纯黑：纯黑在 OLED 上边界过硬、易涂抹，且让「层级」无处表达
玻璃不透明度面板从常规 .72 提到 .78 —— 暗底需要更强的「面」撑起层级
强调色#E8E6E1 而非 #FFF：纯白在深色底上产生光晕（尤其细字）
封面投影暗底上投影看不见 → 改外发光 + 描边：0 0 0 1px var(--line), 0 24px 60px rgba(0,0,0,.6)
唱片沟槽相邻亮度差 ≤ 4%，否则大面积同心圆出摩尔纹
分隔线必须比底色亮（提约 12%）
封面叠层深色下不加白色叠层（显脏）；小封面（<80px）加 1px 描边防糊
浅色必须自带玻璃令牌覆盖。本项目玻璃体系是为暗底写的，翻浅底后白叠层 = 白叠白， 描边 / 轨道 / 悬停会全部消失。需覆盖：--glass-border / --glass-line / --glass-bg / --surface-* / --field-* / --track / --hover。 但别一刀切禁白：--panel / --surface-1 / --glass-line 浅色下本就该是白的，只有分隔类必须压暗。

自动切换：默认跟随 prefers-color-scheme；手动选过以手动为准；在 visibilitychange 回前台时补一次检查。降级：不支持 color-mix() 的环境由主题层提供预计算值，不现场算。

7.5 动效

令牌值用途
--ease-outcubic-bezier(.22,.61,.36,1)默认出场

8 · 切肤生效范围

三层分离：皮肤管布局 / 主题管颜色 / 业务管能力

✅ 皮肤负责

skins/skin.chaoxi.css
  • 布局骨架：侧轨宽度、栅格列数、卡片尺寸、行高、留白节奏
  • 组件位置：控制组顺序、按钮在标题行哪一端、封面尺寸档位
  • 密度与断点：3 / 2 / 1 列（1440 / 900 / 620）
  • 舞台呈现：右侧抽屉 vs 全屏覆盖层
  • 排版字阶（仅 [data-skin="chaoxi"] 作用域）

🎨 主题负责

themes.js CATALOG
  • 全部颜色，含深浅两套
  • 玻璃质感参数（模糊半径、叠层不透明度）
  • 换皮肤不变，换主题才变

⚙️ 业务层负责

app.js / daily.js / …
  • 播放 / 暂停 / 切歌 / seek / 音量 / 收藏的全部逻辑
  • 歌单与曲库数据、搜索召回与排序
  • 设置项本体、账号与登录态
  • 「每日推荐折叠」按钮（所有皮肤共享，不要各写一遍）

三条硬约束（落地最容易踩）

#约束
1皮肤 CSS 不得出现颜色字面量 —— 连 rgba(0,0,0,.5)、#000 都不行；阴影必须走 --shadow-* 令牌
2皮肤 CSS 不得出现交互状态选择器（:hover / :active / :focus / :disabled）—— 状态由主题层 / 基础层统一，否则换主题后状态表现会漂移
3皮肤把业务节点钉成非默认 display 后，hidden 属性会失效（特异性压过 UA 的 [hidden]）—— 收起 / 隐藏一律用皮肤自己的类 + display:none !important

切换与持久化（沿用既有机制）

环节行为

9 · 验收清单

设计与规范两组，逐条勾选

设计与体验

  • 冷启动 → 开始播放 ≤ 3 次点击
  • 播放页可见文字元素 ≤ 6 个
  • 同一视口内 --brand ≤ 1 处
  • 所有 UI 过渡 ≤ 320ms
  • 深 / 浅各跑一遍对比度（正文 ≥ 4.5，次要 ≥ 3）
  • 铜色文字用 #8A6A33，不是 #A98244
  • 4 幅空态插画就位
  • 骨架屏不使用 spinner
  • reduced-motion 下唱片停转、stagger 取消
  • 断点 1440/1024/900/620/390 各截一次

规范合规

  • 皮肤 CSS 零颜色字面量
  • 皮肤 CSS 零交互状态选择器
  • 隐藏 / 收起未依赖 hidden 属性
  • 所有弹层挂在 body 下
  • 定高列里歌词区是唯一滚动区，其余 flex:none
  • 切肤后设置页列表与顶栏弹层高亮一致
  • 排版令牌默认值等于改前 px
  • 浅色主题自带玻璃令牌覆盖

附 · 与 MOO 皮肤体系的对应关系

以下对 MOO 的归纳为设计视角的观察，非其官方规范

MOO 的做法本方案的转译为什么这样转译
极简、大留白，首页几乎看不到卡片用留白与字号差分层级，描边 ≤ 2 处保留气质，但本项目需要可扫读的列表
黑胶 / 唱片机隐喻贯穿播放页480 唱片 + 唱针 + 沟槽，旋转 = 播放状态隐喻直接可感知；并给出「可关闭」开关
UI 单色 + 极少量强调色墨色基底 + 单一铜色点缀铜色比纯黑白更耐看，且能承载「正在播放」语义
动效克制全部过渡 ≤ 320ms，动效需能一句话说明用途把「克制」变成可验收的数值
卡片式、封面为主角封面放大到基线 1.6×，UI 保持单色强化锚点，同时避免整屏彩色打架
日间 / 夜间双模式深浅两套主题，强调色在浅色下反转为墨色直接反色会破坏 AA，必须重排而非反转
