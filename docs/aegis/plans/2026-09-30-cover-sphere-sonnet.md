# 球形封面与彩色商籁

用户已确认：清晰优先的球形粒子封面、彩色商籁、独立可保存的二次元舞台背景；不影响主页。不用 TDD 或 superpowers，不提交、不建分支，保留此前及并发修改。

## 基线与文件边界

- `stage3d.js` 的 silk 场景当前是平面发光点阵，叠加与明暗放大损失封面细节。参照 Mineradio 的 ORBIT 球坐标/UV思路，保留现有 WebGL2 与帧门，不引入 Three.js。
- `folia/folia-theme.js` 当前中性色回退黑白；商籁只接收一主色。参考 VCPChat Musicmodules 的 accent/secondary/ink/background 分工，为商籁提供有彩色但清晰的分层配色，不改变其他歌词模式的默认契约。
- `theme-studio.js` 已管理 12 张内嵌二次元壁纸。复用列表与资源 URL，舞台背景选择单独写入既有 stage3d 设置，不写主页壁纸偏好。
- Stage 继续拥有播放时间和歌曲封面；主题适配层拥有配色；stage3d 编排层拥有舞台背景。ArchitectureReviewRequired: yes。

## 实施顺序

1. 修改 silk 场景为球面点云，校正封面映射、前后深度、点密度与亮度。保留旧场景 id 兼容已保存选项，更新标题说明。先实现后补几何与渲染契约回归。
2. 为商籁解析独立彩色调色板，背景/装饰/重音分色并保护正文对比；保留原有分镜与歌词时间链路。补无封面、中性主题和彩色主题回归。
3. 舞台背景增加二次元图片选项、缩略图选择和明暗调节；保存刷新恢复、图片失败回退、与主页隔离。使用现有图片资源，不复制参考项目图片。
4. 构建到 `target-verify-skin-playback`，用隔离端口与 null backend 验证真实内嵌资源。使用有细节封面及歌词 fixture 截图球面、商籁和图片背景，并检查窄屏、减弱动效、场景切换、保存恢复与性能预算。
5. 运行相关 Node 检查、语法及 diff 检查，独立审查后更新文档与证据。只清理本轮隔离进程。

## 验收与风险

- 封面球面轮廓、原图内容/颜色清楚可辨，背面不透叠；不靠超量粒子或过曝光晕制造效果。低档质量仍受像素预算限制。
- 商籁默认不是黑白，歌词读得清；二次元背景不被不透明 Pixi 底色遮住，背景不抢字。
- 选择与明暗调节即时生效、刷新保存，退出后主页背景不变；隐藏停帧与减少动效不退化。
- 本轮不改播放引擎与网络源取消链路；图像原始分辨率、CORS 与实际 GPU 性能仍是边界。无新配色/图片存储所有者，旧平面封面实现退休。
