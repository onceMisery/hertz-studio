# ADR-0007 · 下一曲预备与集合播放的提交归属

状态：生效（2026-10-08）

## 决定

队列仍由 AppState 持有。集合首页、补页、播放准备都先预留意图，再异步读取，提交时复核；HTTP/RPC 共用 `online_play.rs`。补页会话和播放代际不同：切到本集合另一曲不取消补页，替换整个队列才取消。

音频下一曲只预备本地文件或已经完成的缓存，不在音频回调打开文件。两条解码缓冲由同一个输出回调按帧衔接，actor 将已发生的转场报告给 AppState，AppState 短事务更新游标和实际音质；历史、节拍和网络预取在提交锁外执行。准备、暂停、seek、模式变化、替换/追加队列均有作废规则，Shuffle 保留已有选择规则。

精确 gapless 只承诺两源原生采样率都与设备一致的样本拼接；不同采样率的 crossfade 可分别转换。响度归一化要求新旧增益一致才能预备，避免共享 DSP 把上一曲的增益套在下一曲；其他情况保留普通 Ended 推进。真实压缩格式的编码延迟、驱动声卡听测独立验收，不从 WAV 测试推导。

资料会员状态 `Unknown / Reported{level}` 只是显示提示，不是授权。保留旧 vip 字段供兼容显示，禁止用它们推断可播音质、有效期或权限。没有权威权益端点之前不建立伪权益缓存或新授权门。

## 边界与 owner

| 节拍等待重取次数 | 8 | `plugin/ui/stage-cinema.js::WAIT_RETRIES` | 预算不足时无任务事件的恢复路径、换曲作废和到限回退 |

## 禁止回退

- 不许先 await 集合首页再决定归属：旧歌单迟到会替换新队列；不许无归属地取消补页。
- 不许把“没有 purl / CDN 不可达”解释成已证实无会员，或将网络/限流错误记为永久音质上限。
- 不许从当前偏好推断已失败档位：缓存命中和播放期间改偏好都会使它不同于实际已提交档。
- 回调不许等待锁、分配/释放堆内存，争用时不消耗样本、不推进播放时钟；取消/退休缓冲由 actor 回收。
- 不许把 Transitioned 与后续 Ended/DecodeError 并发处理：极短或损坏的下一曲可能在同一 actor tick 结束。相同代际的空快照可能是随后解码失败，不能丢掉先发生的切换。
- 不许让准备缓存被 LRU 删除，或在追加队列后继续播放原先预备的回卷曲。
- 不许为虚拟列表重新建立曲目 owner；筛选/点击必须使用原始已加载集合和绝对索引。固定队列只改变显示，不发送播放命令。
