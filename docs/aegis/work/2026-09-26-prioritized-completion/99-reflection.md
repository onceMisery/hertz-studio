## 经验

- API 契约脚本（check-library-api.py 的多模式冒烟）在每次重构后都抓住了真实的
  回归（参数编号错位、响应形态变化、重启持久化），是本任务最有效的一道网。
- Web 资源是 include_str! 编译期嵌入：改 JS/CSS 后必须重新 cargo build 才会
  在运行中的服务上生效——浏览器验收前先确认二进制新鲜度。
- 修正契约脚本的源码正则断言（check-creative 扫描身份）时以「保留意图、放宽
  形态」为原则，窗口距离放宽到结构性锚点而非精确距离。
