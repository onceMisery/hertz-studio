# 复盘

- 先检查实际滚动所有者再改 CSS：设置本身超高而祖先裁剪、短屏推荐区域挤压曲库、工作台残留第三列是不同原因，不能统一靠 body overflow 掩盖。
- 实现后回归暴露了正常点击检查发现不了的竞态：顺序不仅是响应 UI 代次，还包括后端命令提交次序；队列编辑不得作废停止，在线准备不得挡住停止。
- 原生浏览器输入与合成生命周期事件分开标注；资源内嵌项目必须重建并验证资源一致性，不能把本地覆盖测试当发布产物验收。
- 保留现有视觉语言，优先修复控件可达性、手势冲突和性能预算，避免为统一风格引入新渲染器。
- 已知底层 I/O 取消缺口没有用虚假 seek 成功或无条件位置归零遮盖，后续需要单独设计源取消协议。
- 按用户要求没有采用 TDD 或 superpowers；没有修改用户曲库、提交代码、建立新分支或停止其他任务的服务。
