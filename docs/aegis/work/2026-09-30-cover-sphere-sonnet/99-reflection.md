# 复盘

- 验证脚本的断言必须覆盖它宣称验收的东西：「切回 3D 恢复球面」只查 class 不查像素，减少动效 15fps 下截图抢在恢复首帧之前，黑画布照样全绿。像素级断言（rAF 内 readPixels 跨帧取最大）才能把名义通过变成真实通过。
- 复现症状先区分产品缺陷与测试时序：移动端黑屏用双时点截图 + 跨帧亮度定位到「截图早于首帧」，避免了去改一个没坏的渲染管线。
- 复现脚本里的「新打开全黑」是偏好异步恢复覆盖了我的 configure，属于复现脚本自己的竞态；症状相同、根因不同，不能合并结论。
- preserveDrawingBuffer=false 时画布取证只能在 rAF 回调内 readPixels；减少动效降帧后并非每个 rAF 都有渲染，单帧采样会误判黑屏。
- 内嵌资源项目的时间戳链要核对：构建产物必须晚于全部 web 资源改动，浏览器脚本再做逐字比对，双保险才敢把截图当发布产物证据。
