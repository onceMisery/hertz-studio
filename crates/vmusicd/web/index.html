    设置

    界面皮肤

    皮肤只管布局。换皮肤不会动主题色，换主题也不会破坏皮肤。

    音效与均衡器

    远程来源（WebDAV）

    密码存入系统钥匙串，不进数据库与备份。导入的曲目以 HTTP 直链播放，需要服务器支持 Range 请求。

    在线缓存

    —

    在线试听的音频会先落盘缓存。当前播放与保留名单里的曲目不会被清理。

    数据备份

    备份含歌单、收藏、设置与曲库目录，不含平台凭据。导入按名字合并歌单、收藏去重，可重复执行。

    外观

    开启时背景与舞台高亮跟随封面；关闭后使用所选主题，保留歌曲封面。即时生效并自动保存。
    没有曲目在播或已按停止时收起右侧舞台，列表占满宽度；开始播放自动恢复
    —

    导航

    在左侧导航里显示独立的每日推荐入口；关掉后入口消失，不影响其它菜单

    创意舞台

    工坊里可以编排 cue 轨、把参数绑到音频、换背景、开手绘风格， 并把这些整体存成一份预置或导出成 JSON。全部参数实时生效，不需要重新加载界面。

    在线音源

    这里填的是你自己在该站点的登录 cookie，服务端只会把它作为 Cookie 头 发给那个站点自己的公开接口，和浏览器登录后的行为一致。填了之后退出再进也会 保留；清空输入框并保存即可退出。本项目不解密受保护音频、不绕过付费内容， 也不模拟任何站点的反爬签名或设备指纹。

    开启后把播放过程逐条写进日志文件：选了哪个音源与音质、走缓存还是现下载、地址是哪个（隐去签名参数）、以及失败原因。内容只与播放有关，会带上在播曲名与本地文件路径，不含账号凭据。遇到问题时先开启再复现一次，然后把下面的日志发给开发者。
