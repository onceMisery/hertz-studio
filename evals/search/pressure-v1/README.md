# 搜索共享额度的受控混合压力记录 v1

2026-10-18，当前 Windows 未提交开发工作区的 Standard / Full 各运行一轮显式探针。实际 HTTP 路由、`Rpc::call`、单源和旧聚合共用原 AppState / SearchGate；只替换已登记 provider 的网络读取，不调用平台协议、真实来源、账号、模型或声卡。方法、完整命令与边界见[搜索性能说明](../../../docs/search-performance.md)。

本轮使用 Windows `10.0.26200`、Intel Core i7-13620H、16 逻辑核、约 32 GiB 内存，rustc 1.98.1；test profile、四个 runtime worker、关闭增量与 dev/test 调试信息。HEAD 为 `401a90376c0fa8391b5d60234103eeb381ef2c2c` 加未提交改动，使用隔离 C 盘 target，不覆盖运行中的播放器。这不是 release 性能、真实宿主或冻结候选包验收。

| 指标 | Standard | Full |
| --- | --- | --- |
| 混合阶段持续时间 | 60.46 秒 | 60.11 秒 |
| 每波 32 次调用的波数 | 126 | 129 |
| 混合阶段客户端调用数，含 busy 与取消 | 4032 | 4128 |
| 本地搜索 future 执行峰值 | 4 | 4 |
| 上游 socket handler 观测峰值 | 5 | 4 |
| 满席后额外请求的 busy 返回 | 3.58 ms | 4.06 ms |
| 四个响应体停顿案例的超时范围 | 6008.88–6010.57 ms | 6006.95–6007.68 ms |
| 上游已读取请求数 | 2280 | 2312 |
| 完整回复 / 已观察断开 | 2115 / 165 | 2152 / 160 |
| 结束后可用执行槽 / 等待席 | 4 / 16 | 4 / 16 |

本地计数随实际网络与解析 future 的生命周期释放；上游计数还包含尚未处理取消 EOF 的 handler。Standard 的短暂 socket 峰值五不能等同五个本地执行；每波两种计数均归零，上游已读取请求与回复/断开计数相符。两版最后的本地执行数为零，额外成功查询通过。聚合的外层 200 包含部分来源失败，不能把它当作全部来源成功；各入口的外层状态分布保留在摘要中。固定超额负载让部分入口大量得到 busy，本记录不证明负载下的公平性或用户体验指标达标。

探针还先占满四执行槽和十六等待席，再取消混合 HTTP/RPC 调用并等待实际回收。开发期间修正了夹具把“连接已建立但尚无 HTTP 内容即关闭”当作非法请求的错误，并区分本地执行与上游关闭观察的统计口径；没有把这些探针问题当作播放器缺陷或修改搜索额度的理由。

原始逐调用记录以 gzip 压缩保留：[Standard](./windows-x64-standard-20261018.json.gz)、[Full](./windows-x64-full-20261018.json.gz)。[摘要](./summary.json)包含环境、原始/压缩字节 hash、测试二进制与九个源码/依赖文件指纹，以及完整计数和外层状态分布。源码字节嵌入编译产物，运行前后与磁盘一致；归档时又独立核对源码指纹、每波/客户端唯一身份、状态白名单与计数对账。原始记录可用 Python 标准库读取，无额外包：

```powershell
python -c "import gzip,json; r=json.load(gzip.open('evals/search/pressure-v1/windows-x64-standard-20261018.json.gz')); print(r['results']['peakLocalExecution'])"
```

这些记录证明本机本轮受控负载的结构额度、恢复与真实期限行为，仍不冻结 4/16/2 秒/6 秒候选值。超过六十秒的压力、全进程 RSS、实际来源与网络、真实 DBX/浏览器混合旅程、弱机和其它 OS 均未由本探针验收。平台归一化也没有经过本 fixture；五万曲与真实 Chrome 首结果基线仍是[另一组测量](../v1/README.md)。所有报告保留 `releaseEligible: false`，R0 / R1-S 与整体路线图仍未完成。

后续[长时受控压力 v2](../pressure-v2/README.md)已另存两版三轮各两分钟的原始记录、头/体期限与排队边界、测试进程内存及独立复核。它包含同进程 Rust 驱动和回环上游，仍不等于生产服务独立 RSS 或四入口有效吞吐验收；本页历史环境和数值保持原样。
