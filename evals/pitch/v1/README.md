# 基频候选合成评测 v1

这组评测验证 `vmusic-beats::pitch` 的周期估计，不验证多声部歌曲的主旋律、听感或音乐结构。当前报告 `syntheticOnly=true`、`realMusicAccepted=false`；不据此宣布 R6 全部完成。

从仓库根目录运行：

```powershell
cargo test --locked -p vmusic-beats
cargo run --locked -p vmusic-beats --example pitch_evaluation -- evals/pitch/v1/synthetic-20261018.json
```

报告保留[2026-10-18 合成结果](./synthetic-20261018.json)。固定 37 个一秒信号：55/60/110/220/440/880/1200 Hz，分别以 8/44.1/48/96 kHz 输入；另有缺失基频的谐波、直流偏置、常量直流、静音、低于门限、高于范围、抗混叠、固定种子噪声和频率跳变。全部使用生产同源低通、重采样和估计器。

预先写定单点误差不超过 35 cents、每例至少 95% 的评分点正确。预期无声时必须输出 null；有声时 null 算失败，错误倍频也按真实误差评分。仅频率跳变两侧 128 毫秒不评分，因窗口跨越两段，不把过渡定义成静音。报告仍列完整点数、评分分母、正确数、非空数与有声误差；不按检测成功的点缩小分母。额外回归覆盖短输入、非有限样本、不支持采样率、取消、期限和恰好/超过 720 秒的输出上限。

服务检查另验证实际 WAV 解码、完整内容 SHA-256、相同路径改写后的缓存失效、相同内容换路径的缓存命中、共享节拍预算、本地限制、HTTP/RPC 传输一致及无播放副作用。浏览器检查实际 30 秒 WAV 的 220 Hz→静音→440 Hz、暂停/seek、切歌和观察生命周期；忙/旧版本/迟到响应是明确注入的客户端情境，不冒充真实模型或解码器行为。

仍需真实音乐独立标注、不同编码的时间对齐、噪声/多声部/八度错误、CPU/内存/弱机与原生宿主评估。报告运行时间只包含当前合成计算，不是文件哈希/解码或整首歌曲的 P95；没有正式质量发布资格。
