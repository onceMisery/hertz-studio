## 已落地的使用路径

主应用“一起听”作为入口，进入大厅、房间播放、邀请、共同队列与聊天、成员与设置五页工作区。桌面侧栏与分栏，手机视口大封面、底部导航及队列／聊天分段。返回 Hertz 保持房间，恢复紧凑播控；进入工作区后隐藏重复播控。

真实功能包括局域网发现及开关、建房、受限共享曲库、一次性邀请／二维码／撤销、查找码申请及房主审批、成员权限、原生音频输出、播放／跳转／循环随机、共同队列、点歌人、实例投票及房主票序、文本与歌曲卡片聊天、活动、音效、睡眠定时和退出生命周期。界面使用真实房间投影；未取得遥测时不显示虚构的声学误差或缓冲百分比。

服务端 AppState 唯一拥有业务队列；Host 拥有协作状态；RenderCore 统一产生 PCM；Receiver 唯一拥有设备输出。前端 `room.js` 拥有会话、请求、回执及资源，`room-workspace.js` 与 `room-view.js` 负责页面。新增能力走正式协议与权限合同，不复制播放器或另建权威状态。见 [ADR-0011](../../../docs/adr/0011-lan-rendering-and-output-ownership.md) 与 [设计](../../../docs/plans/2026-10-25-listening-workspace-design.md)。

## 修复与健壮性覆盖

- 同成员重连保留草稿和未知回执；换房／成员隔离旧操作；未知写请求不自动重放，也不被下一次播控覆盖。
- 重复歌曲按队列实例计票，单成员至多一票；票序保持当前实例和已冻结音频前缀，平票顺序确定。
- 结构化歌曲卡片持久化；撤销分享立即移除可操作资源投影，拒绝迟到资源响应；封面更新释放旧对象 URL。
- 聊天数据库 schema 1→2 使用事务性新增列，避免接近配额时复制整表。6000 条长消息、16 MiB 配额、约 90% 页占用的迁移回归通过。
- 八位查找码只用于申请；批准前无成员、PCM、共享资源或聊天权；256-bit 申请秘密、限流、有界队列、超时及原子消费。
- 邀请权独立授权；成员只转授自己已有的基础收听和聊天权。邀请消费后不假报撤销成功；房主可移除实际成员。
- 审批加入失败保留申请；查询不重放 Join；重试前核对服务器状态；已消费授权不重复使用。
- 后台读取遇到 revision conflict 清理读取签名并刷新；权限／存储失败及用户写冲突继续呈现；不自动重放写入。
- 协议升级为 wire v3 并拒绝旧握手／PCM；邀请封装的 v1 标记不代表线协议版本。

## 复现与使用

构建、加入、端口／凭据要求与完整验收命令见 [使用指南](../../../docs/lan-listening-user-guide.md)。核心命令：

```powershell
cargo build -p hertz-studio --bin hertz-studio
python scripts/check-lan-room.py --binary target/debug/hertz-studio.exe --report output/lan-control.json
python scripts/check-lan-room.py --binary target/debug/hertz-studio.exe --native-output --duration 120 --report output/lan-native.json
node scripts/check-frontend.js
```

人工 UI 路径：分别启动两个独立数据目录；房主导入并分享曲目、创建房间；接收电脑粘贴邀请并核验完整指纹；点歌、投票、分享歌曲到聊天；房主切换票序并播放。按上述六种视口依次切换五页，核对键盘、草稿、返回与重新进入。凭据、profile、邀请正文和浏览器认证文件不随证据提交。

## 尚未覆盖与交付边界

用户于 2026-10-25 确认本轮范围为**电脑局域网功能及小屏响应式布局**。手机独立客户端、远程连接入口和音频接收不在本版范围；互联网身份／好友／公共目录／异地连接留待后续接入。上述范围已确认，不再作为交付待确认项。手机截图仅证明布局适配。房间共享歌曲的个人收藏仍未实现；返回现有音乐库／收藏入口不等于新增房间收藏能力。

实际设备验收为 Windows 单机双进程、音量为零的 WASAPI 输出；不是两台电脑的声学测量。macOS/Linux 原生设备、跨机／跨系统声学精度、八端压力、八小时真机长稳、睡眠唤醒和设备热拔插矩阵仍待实机验收。CI 已配置三平台两版本，但本地交付没有观察远程矩阵执行。

当前房间固定采样率、双声道 f32 PCM，不增加有损编码；混音、DSP、源格式转换和设备漂移补偿可能改变采样，不能宣称 bit-perfect。不存在已测得的跨机声学误差保证。
